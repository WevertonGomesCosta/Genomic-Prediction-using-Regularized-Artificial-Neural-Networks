# Output

This directory contains derived analytical objects, fitted-model results,
predictions, summaries, and publication-ready artifacts generated by the
project.

Source data remain under `data/`. Temporary runtime files, logs, checkpoints,
and debugging artifacts are not part of the versioned scientific-output contract.

## Layout

```text
output/
├── simulated/
│   ├── audit/
│   ├── validation/
│   ├── gblup/
│   ├── ann/
│   │   ├── tuning/
│   │   └── final/
│   └── comparison/
└── real/
    ├── phenotype/
    ├── audit/
    ├── validation/
    ├── gblup/
    ├── ann/
    │   ├── tuning/
    │   └── final/
    └── comparison/
```

## Simulated-data outputs

`output/simulated/audit/` contains the common prepared simulated-data object and
the summaries required downstream.

`output/simulated/validation/` contains the shared outer and inner partition
assignments.

`output/simulated/gblup/` contains GBLUP-ADE predictions, performance
summaries, kernel summaries, and execution metadata.

`output/simulated/ann/tuning/` contains training-only ANN hyperparameter
selection results, while `output/simulated/ann/final/` contains final ANN
predictions, performance summaries, epoch-selection results, and execution
metadata.

`output/simulated/comparison/` contains the terminal model-comparison
summaries.

## Real-data outputs

### Phenotypic analysis

`output/real/phenotype/` contains the products of
`analysis/real_data_phenotype.Rmd`, including:

- descriptive summaries of the longitudinal field data;
- mixed-model variance-component summaries;
- final individual genotypic BLUPs for each target trait;
- machine-readable BLUP objects consumed by the data-integration stage;
- execution metadata describing the phenotypic model specification.

Genomic marker data are not used to create these outputs.

### Data integration and genotype preparation

`output/real/audit/` contains the products of `analysis/real_data_audit.Rmd`.

This stage aligns the phenotypic BLUPs with `geno_real.rds`, performs marker
quality control, and creates the common real-data object used downstream.

### Validation design

`output/real/validation/` contains the common outer and inner partitions used
by GBLUP-ADE and ANN models.

### GBLUP-ADE

`output/real/gblup/` contains held-out GBLUP-ADE predictions, performance
summaries, genomic-kernel information, and execution metadata.

### ANN

`output/real/ann/tuning/` contains ANN hyperparameter-selection results based
only on the corresponding analysis samples.

`output/real/ann/final/` contains final ANN predictions, performance summaries,
epoch-selection results, and execution metadata.

### Model comparison

`output/real/comparison/` contains terminal task-matched comparisons between
GBLUP-ADE and the ANN configurations.

The comparison stage reads saved model outputs and does not refit either model
family.

## Runtime artifacts

Files required only during execution, such as temporary checkpoints, logs, or
intermediate debugging objects, are not part of the canonical repository or
scientific-output hierarchy.

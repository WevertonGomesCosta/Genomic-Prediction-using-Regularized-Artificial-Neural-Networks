Purpose

This module fits the canonical GBLUP-ADE benchmark to all six simulated scenarios using the 25 frozen outer validation splits. Phenotypes are used for model fitting. True simulated genetic values are used only after prediction for primary evaluation of genetic-value recovery.

GBLUP-ADE model

The benchmark predicts each phenotype from three genomic components:

\[ \mathbf{y} = \mathbf{1}\mu + \mathbf{a} + \mathbf{d} + \mathbf{e} + \boldsymbol{\varepsilon}. \]

Objects in the model

Object Meaning
\(\mathbf{y}\) phenotype vector for one simulation scenario
\(\mu\) overall intercept
\(\mathbf{a}\) additive genomic effect
\(\mathbf{d}\) dominance genomic effect
\(\mathbf{e}\) epistatic genomic effect
\(\boldsymbol{\varepsilon}\) residual

The three genetic components are modeled as random effects:

\[ \mathbf{a}\sim N(0,\mathbf{A}\sigma_a^2),\qquad \mathbf{d}\sim N(0,\mathbf{D}\sigma_d^2), \]

\[ \mathbf{e}\sim N(0,\mathbf{E}\sigma_e^2),\qquad \boldsymbol{\varepsilon}\sim N(0,\mathbf{I}\sigma_\varepsilon^2). \]

Genomic relationship matrices

Matrix Role
\(\mathbf{A}\) additive genomic relationships
\(\mathbf{D}\) dominance genomic relationships
\(\mathbf{E}\) epistatic genomic relationships

The matrices are built from the marker data with sommer::A.mat(), sommer::D.mat(), and sommer::E.mat(). They describe covariance among individuals; they are not additional response variables.

sommer implementation

In sommer::mmes(), ism() identifies the individual levels associated with each random effect and vsm() connects that effect to the corresponding genomic relationship matrix through Gu.

The canonical fit uses nIters = 20 for every scenario and outer split. This is a fixed fitting control, not a tuned hyperparameter.

The predicted genetic value is the sum

\[ \widehat{G}=\widehat{a}+\widehat{d}+\widehat{e}, \]

and the phenotype prediction adds the fitted intercept to this genetic component.

Fixed fitting control

The number of sommer::mmes() iterations is fixed for every scenario and outer split. It is part of the benchmark specification and is not selected from the data.

N_ITERS_SOMMER <- 20L

The same value, nIters = 20, is therefore used in all 150 fits.

Evaluation metrics

The held-out predictions are summarized with correlation, RMSE, MAE, bias, calibration slope, and \(R^2\). The functions below assume the audited canonical assessment vectors are finite.

safe_cor <- function(pred, obs) {
  cor(pred, obs)
}

safe_rmse <- function(pred, obs) {
  sqrt(
    mean(
      (pred - obs)^2
    )
  )
}

safe_mae <- function(pred, obs) {
  mean(
    abs(
      pred - obs
    )
  )
}

safe_bias <- function(pred, obs) {
  mean(
    pred - obs
  )
}

safe_slope <- function(pred, obs) {
  as.numeric(
    coef(
      lm(
        obs ~ pred
      )
    )[2]
  )
}

safe_r2 <- function(pred, obs) {
  total_variation <- sum(
    (
      obs -
      mean(obs)
    )^2
  )

  1 -
    sum(
      (
        obs -
        pred
      )^2
    ) /
    total_variation
}

metrics <- function(
  pred,
  obs,
  prefix
) {
  values <- c(
    safe_cor(pred, obs),
    safe_rmse(pred, obs),
    safe_mae(pred, obs),
    safe_bias(pred, obs),
    safe_slope(pred, obs),
    safe_r2(pred, obs)
  )

  names(values) <- paste0(
    prefix,
    c(
      "_Correlation",
      "_RMSE",
      "_MAE",
      "_Bias",
      "_Slope",
      "_R2"
    )
  )

  values
}

For bias, positive values indicate overprediction because the definition is mean(predicted - observed). The calibration slope is obtained from observed ~ predicted, and \(R^2\) is computed as \(1-SSE/SST\).

Recovering genomic components

sommer::mmes() stores the fitted additive, dominance, and epistatic random effects in fit$uList. The helper below maps each fitted random-effect vector back to the 1,000 individuals through the corresponding model matrix.

extract_u <- function(
  fit,
  dat,
  factor_name,
  effect_name
) {
  random_effect <- as.matrix(
    fit$uList[[effect_name]]
  )

  incidence_matrix <- model.matrix(
    as.formula(
      paste0(
        "~",
        factor_name,
        " - 1"
      )
    ),
    data = dat
  )

  as.numeric(
    incidence_matrix %*%
      random_effect[
        ,
        1L,
        drop = FALSE
      ]
  )
}

The three calls later in the fitting loop differ only in the factor and relationship-matrix names (id/A, idd/D, and ide/E).

Fit GBLUP-ADE

The A, D, and E relationship matrices are built once from the complete genotype matrix and reused across tasks. All genotype profiles may contribute to these relationship matrices because genomic information is available at prediction time.

For each outer split, however, the phenotypes of the 200 assessment individuals are replaced by NA before fitting. Consequently, those individuals contribute genomic relationships but not response information. Their true genetic values are also excluded from fitting and are accessed only after prediction for performance evaluation.

One representative fit

The essential model call for one scenario and one outer split is:

fit <- sommer::mmes(
  y ~ 1,
  random = ~
    vsm(ism(id),  Gu = A_matrix) +
    vsm(ism(idd), Gu = D_matrix) +
    vsm(ism(ide), Gu = E_matrix),
  rcov = ~ units,
  nIters = 20,
  data = dat,
  verbose = FALSE
)

Here dat$y contains phenotype values for the analysis individuals and NA for the 200 outer-assessment individuals. The matrices A_matrix, D_matrix, and E_matrix are shared across tasks; only the scenario and frozen assessment set change.

The code below repeats this fitting logic over all 150 frozen tasks. The loop follows the successful canonical path directly: identify the split, mask the assessment phenotypes, fit GBLUP-ADE, recover the three genomic components, predict the held-out individuals, and store the metrics.

    Dominance_Prediction = dominance[assessment_index],
    Epistatic_Prediction = epistatic[assessment_index],
    Status = "ok",
    stringsAsFactors = FALSE
  )

  cat(
    sprintf(
      "[%03d/%03d] %s | rG=%.4f | RMSE_G=%.4f | fit=%.2fs\n",
      i,
      nrow(task_table),
      task$TaskID,
      result_list[[i]]$Genetic_Correlation,
      result_list[[i]]$Genetic_RMSE,
      fit_seconds
    )
  )
}

Kernel diagnostics

Numerical integrity of the additive, dominance, and epistatic relationship matrices is checked before saved predictions are interpreted. The detailed kernel table is retained as an output artifact; the reader-facing page reports the scientifically relevant structural summary.

The saved diagnostics contain three 1,000 × 1,000 genomic relationship matrices. All three are finite and symmetric, with mean diagonal values close to one. This confirms that the additive, dominance, and epistatic covariance structures are numerically suitable for interpreting the fitted predictions.

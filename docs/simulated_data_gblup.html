1. Objective

This module fits the canonical GBLUP-ADE benchmark to all six simulated scenarios using the 25 frozen outer validation splits. Phenotypes are used for model fitting. True simulated genetic values are used only after prediction for primary evaluation of genetic-value recovery.

1.1 How to read this module

The module first identifies the canonical inputs and fixed fitting controls, then defines the GBLUP-ADE model and evaluation metrics. The six scenarios are crossed with the 25 frozen outer splits to create 150 fitting tasks. Saved results are then summarized with true genetic value as the primary evaluation target and phenotype as the secondary target.

The outer assessment phenotypes remain unavailable to model fitting. Genomic relationships can include all individuals because marker information is available at prediction time, whereas true simulated genetic values are accessed only after held-out predictions have been generated.

3. GBLUP-ADE model

3.1 Statistical model

The benchmark predicts each phenotype from additive, dominance, and epistatic genomic components:

\[ \mathbf{y} = \mathbf{1}\mu + \mathbf{a} + \mathbf{d} + \mathbf{e} + \boldsymbol{\varepsilon}. \]

The three genetic components are modeled as random effects:

\[ \mathbf{a}\sim N(0,\mathbf{A}\sigma_a^2),\qquad \mathbf{d}\sim N(0,\mathbf{D}\sigma_d^2), \]

\[ \mathbf{e}\sim N(0,\mathbf{E}\sigma_e^2),\qquad \boldsymbol{\varepsilon}\sim N(0,\mathbf{I}\sigma_\varepsilon^2). \]

3.2 Additive relationship matrix

The additive component uses the genomic relationship matrix \(\mathbf{A}\), constructed from the marker matrix with sommer::A.mat(). It represents additive genomic covariance among the 1,000 individuals.

3.3 Dominance relationship matrix

The dominance component uses \(\mathbf{D}\), constructed with sommer::D.mat(). It represents covariance associated with dominance genomic effects.

3.4 Epistatic relationship matrix

The epistatic component uses \(\mathbf{E}\), constructed with sommer::E.mat(). It represents the epistatic genomic covariance structure used by this prespecified benchmark.

3.5 Predicted genetic value

In sommer::mmes(), ism() identifies the individual levels associated with each random effect and vsm() connects that effect to the corresponding genomic relationship matrix through Gu.

The predicted genetic value is

\[ \widehat{G}=\widehat{a}+\widehat{d}+\widehat{e}, \]

and the final phenotype-scale prediction adds the fitted intercept to this genetic component.

4. Evaluation metrics

The held-out predictions are summarized with correlation, RMSE, MAE, bias, calibration slope, and \(R^2\). The functions below assume the audited canonical assessment vectors are finite.

safe_cor <- function(pred, obs) {
  cor(pred, obs)
}

safe_rmse <- function(pred, obs) {
  sqrt(
    mean(
      (pred - obs)^2
    )
  )
}

safe_mae <- function(pred, obs) {
  mean(
    abs(
      pred - obs
    )
  )
}

safe_bias <- function(pred, obs) {
  mean(
    pred - obs
  )
}

safe_slope <- function(pred, obs) {
  as.numeric(
    coef(
      lm(
        obs ~ pred
      )
    )[2]
  )
}

safe_r2 <- function(pred, obs) {
  total_variation <- sum(
    (
      obs -
      mean(obs)
    )^2
  )

  1 -
    sum(
      (
        obs -
        pred
      )^2
    ) /
    total_variation
}

metrics <- function(
  pred,
  obs,
  prefix
) {
  values <- c(
    safe_cor(pred, obs),
    safe_rmse(pred, obs),
    safe_mae(pred, obs),
    safe_bias(pred, obs),
    safe_slope(pred, obs),
    safe_r2(pred, obs)
  )

  names(values) <- paste0(
    prefix,
    c(
      "_Correlation",
      "_RMSE",
      "_MAE",
      "_Bias",
      "_Slope",
      "_R2"
    )
  )

  values
}

For bias, positive values indicate overprediction because the definition is mean(predicted - observed). The calibration slope is obtained from observed ~ predicted, and \(R^2\) is computed as \(1-SSE/SST\).

7. Fitting procedure

The A, D, and E relationship matrices are built once from the complete genotype matrix and reused across tasks. All genotype profiles may contribute to these relationship matrices because genomic information is available at prediction time.

For each outer split, the phenotypes of the 200 assessment individuals are replaced by NA before fitting. Consequently, those individuals contribute genomic relationships but not response information. Their true genetic values are accessed only after prediction for performance evaluation.

sommer::mmes() stores the fitted additive, dominance, and epistatic random effects in fit$uList. The helper below maps each fitted random-effect vector back to the 1,000 individuals through the corresponding model matrix.

extract_u <- function(
  fit,
  dat,
  factor_name,
  effect_name
) {
  random_effect <- as.matrix(
    fit$uList[[effect_name]]
  )

  incidence_matrix <- model.matrix(
    as.formula(
      paste0(
        "~",
        factor_name,
        " - 1"
      )
    ),
    data = dat
  )

  as.numeric(
    incidence_matrix %*%
      random_effect[
        ,
        1L,
        drop = FALSE
      ]
  )
}

The three calls in the fitting loop differ only in the factor and relationship-matrix names (id/A, idd/D, and ide/E).

7.1 One representative fit

The essential model call for one scenario and one outer split is:

fit <- sommer::mmes(
  y ~ 1,
  random = ~
    vsm(ism(id),  Gu = A_matrix) +
    vsm(ism(idd), Gu = D_matrix) +
    vsm(ism(ide), Gu = E_matrix),
  rcov = ~ units,
  nIters = 20,
  data = dat,
  verbose = FALSE
)

Here dat$y contains phenotype values for the analysis individuals and NA for the 200 outer-assessment individuals. The matrices A_matrix, D_matrix, and E_matrix are shared across tasks; only the scenario and frozen assessment set change.

    isTRUE(all.equal(D_matrix, t(D_matrix), tolerance = 1e-8)),
    isTRUE(all.equal(E_matrix, t(E_matrix), tolerance = 1e-8))
  ),
  Finite = c(
    all(is.finite(A_matrix)),
    all(is.finite(D_matrix)),
    all(is.finite(E_matrix))
  ),
  Mean_diagonal = c(
    mean(diag(A_matrix)),
    mean(diag(D_matrix)),
    mean(diag(E_matrix))

  Kernel_build_seconds = rep(kernel_seconds, 3L),

for (i in seq_len(nrow(task_table))) {
  task <- task_table[i, ]
  scenario <- task$Scenario
  scenario_index <- match(
    scenario,
    scenario_names
  )

  # Identify the frozen analysis and assessment individuals for this task.
  split <- cv$outer_splits[[task$SplitID]]

  analysis_index <- match(
    split$analysis_ids,
    ids
  )
  assessment_index <- match(
    split$assessment_ids,
    ids
  )

  phenotype_vector <- phenotype[
    ,
    scenario_index
  ]
  true_genetic_vector <- true_g[
    ,
    scenario_index
  ]

  id_factor <- factor(
    id_labels,
    levels = id_labels
  )

  dat <- data.frame(
    y = phenotype_vector,
    id = id_factor,
    idd = id_factor,
    ide = id_factor
  )

  # Withhold outer-assessment phenotypes before fitting the model.
  dat$y[assessment_index] <- NA_real_

  fit_start <- proc.time()[["elapsed"]]

  # Fit the prespecified additive + dominance + epistatic mixed model.
  fit <- sommer::mmes(
    y ~ 1,
    random = ~
      vsm(ism(id), Gu = A_matrix) +
      vsm(ism(idd), Gu = D_matrix) +
      vsm(ism(ide), Gu = E_matrix),
    rcov = ~ units,
    nIters = N_ITERS_SOMMER,
    data = dat,
    verbose = FALSE,
    dateWarning = FALSE
  )

  fit_seconds <- proc.time()[["elapsed"]] - fit_start

  prediction_start <- proc.time()[["elapsed"]]

  # Recover the three fitted genomic components for all individuals.
  additive <- extract_u(
    fit,
    dat,
    "id",
    "vsm(ism(id), Gu = A_matrix)"
  )
  dominance <- extract_u(
    fit,
    dat,
    "idd",
    "vsm(ism(idd), Gu = D_matrix)"
  )
  epistatic <- extract_u(
    fit,
    dat,
    "ide",
    "vsm(ism(ide), Gu = E_matrix)"
  )

  gebv <- additive + dominance + epistatic
  intercept <- as.numeric(fit$b)[1L]
  predicted_value <- intercept + gebv

  predict_seconds <- proc.time()[["elapsed"]] - prediction_start

  # Evaluate predictions only on the untouched outer-assessment individuals.
  observed_test <- phenotype_vector[
    assessment_index
  ]
  true_g_test <- true_genetic_vector[
    assessment_index
  ]
  predicted_test <- predicted_value[
    assessment_index
  ]
  gebv_test <- gebv[
    assessment_index
  ]

  genetic_metrics <- metrics(
    predicted_test,
    true_g_test,
    "Genetic"
  )
  phenotype_metrics <- metrics(
    predicted_test,
    observed_test,
    "Phenotype"
  )

  meta <- control[
    control$Scenario == scenario,
    ,
    drop = FALSE
  ]

    Scenario = scenario,

    Genetic_MAE =
      genetic_metrics["Genetic_MAE"],
    Genetic_Bias =
      genetic_metrics["Genetic_Bias"],
    Genetic_Slope =
      genetic_metrics["Genetic_Slope"],
    Genetic_R2 =
      genetic_metrics["Genetic_R2"],
    GEBV_TrueG_Correlation =
      safe_cor(gebv_test, true_g_test),
    Phenotype_Correlation =
      phenotype_metrics["Phenotype_Correlation"],
    Phenotype_RMSE =
      phenotype_metrics["Phenotype_RMSE"],
    Phenotype_MAE =
      phenotype_metrics["Phenotype_MAE"],
    Phenotype_Bias =
      phenotype_metrics["Phenotype_Bias"],
    Phenotype_Slope =
      phenotype_metrics["Phenotype_Slope"],
    Phenotype_R2 =

    Fit_seconds = fit_seconds,
    Predict_seconds = predict_seconds,

    H2_nominal = meta$H2_nominal,
    Repetition = task$Repetition,
    Fold = task$OuterFold,
    SplitID = task$SplitID,
    TaskID = task$TaskID,
    Model = "GBLUP_ADE",
    ID = ids[assessment_index],
    Observed_Phenotype = observed_test,
    True_Genetic_Value = true_g_test,

    Dominance_Prediction = dominance[assessment_index],

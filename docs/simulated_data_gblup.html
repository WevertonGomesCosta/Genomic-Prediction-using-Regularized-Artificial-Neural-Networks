Purpose

This module fits the canonical GBLUP-ADE benchmark to all six simulated scenarios using the 25 frozen outer validation splits. Phenotypes are used for model fitting. True simulated genetic values are used only after prediction for primary evaluation of genetic-value recovery.

Canonical inputs

The GBLUP-ADE branch uses the audited simulated-data object and the frozen validation design created in the preceding modules. The canonical dataset contains 1,000 individuals, 4,010 markers, six simulation scenarios, and 25 outer validation splits. These inputs are checked before any model result is used.

GBLUP-ADE model

For each scenario and frozen outer split, the phenotype is modeled as

\[ \mathbf{y} = \mathbf{1}\mu + \mathbf{a} + \mathbf{d} + \mathbf{e} + \boldsymbol{\varepsilon}, \]

where \(\mu\) is the intercept, \(\mathbf{a}\) is the additive genomic effect, \(\mathbf{d}\) is the dominance effect, \(\mathbf{e}\) is the epistatic effect, and \(\boldsymbol{\varepsilon}\) is the residual.

The corresponding covariance structures are

\[ \mathbf{a} \sim N(0,\mathbf{A}\sigma_a^2),\quad \mathbf{d} \sim N(0,\mathbf{D}\sigma_d^2), \]

\[ \mathbf{e} \sim N(0,\mathbf{E}\sigma_e^2),\quad \boldsymbol{\varepsilon} \sim N(0,\mathbf{I}\sigma_{\varepsilon}^2). \]

At the scientific level, \(\mathbf{A}\), \(\mathbf{D}\), and \(\mathbf{E}\) are three genomic relationship structures built from the marker data. They specify how covariance is shared among individuals for each random genetic component of the same phenotype:

  • \(\mathbf{A}\) represents additive genomic relationship and structures the covariance of the additive effects \(\mathbf{a}\);
  • \(\mathbf{D}\) represents dominance genomic relationship and structures the covariance of the dominance effects \(\mathbf{d}\);
  • \(\mathbf{E}\) represents the epistatic genomic relationship used by this benchmark and structures the covariance of the epistatic effects \(\mathbf{e}\).

These matrices are covariance structures, not additional response variables. The model combines the three predicted genetic components to represent the total predicted genetic value for each individual.

The genomic relationship matrices \(\mathbf{A}\), \(\mathbf{D}\), and \(\mathbf{E}\) are constructed with sommer::A.mat(), sommer::D.mat(), and sommer::E.mat(), respectively. In sommer::mmes(), ism() identifies the individual levels associated with each random effect and vsm() links that effect to its genomic covariance matrix through Gu.

The canonical fitting protocol uses nIters = 20. This value is fixed across all scenarios and outer splits and is not a tuned model-selection parameter.

The total predicted genetic component used for evaluation is the sum of the additive, dominance, and epistatic predictions. The model intercept is added when predicting the phenotype.

Pre-fit integrity

Before any saved result is summarized, the canonical phenotype, true-genetic- value, genotype, scenario, and frozen outer-split dimensions are checked internally. A blocking mismatch stops the module rather than allowing a result table to be interpreted against an inconsistent input contract.

Fit GBLUP-ADE

The A, D, and E relationship matrices are built once from the complete genotype matrix and reused across tasks. All genotype profiles may contribute to these relationship matrices because genomic information is available at prediction time.

For each outer split, however, the phenotypes of the 200 assessment individuals are replaced by NA before fitting. Consequently, those individuals contribute genomic relationships but not response information. Their true genetic values are also excluded from fitting and are accessed only after prediction for performance evaluation.

set.seed(SEED_GLOBAL)

Kernel diagnostics

Numerical integrity of the additive, dominance, and epistatic relationship matrices is checked before saved predictions are interpreted. The detailed kernel table is retained as an output artifact; the reader-facing page reports the scientifically relevant structural summary.

The canonical diagnostics contain three 1,000 x 1,000 relationship matrices. All three are finite and symmetric, and their mean diagonal values are close to one. These checks support the numerical integrity of the additive, dominance, and epistatic covariance structures before interpreting predictions.

Saved-result integrity

The saved canonical results are checked against the frozen validation contract before performance aggregation. Task count, prediction count, split IDs, successful status, and prediction finiteness remain blocking or warning checks, but the detailed PASS table is kept out of the main narrative.

For the canonical saved results, the audit verifies 150 unique scenario-by-split tasks and 30,000 held-out predictions, corresponding to 200 assessment individuals per task. The frozen split identifiers and prediction finiteness are checked before any performance summary is interpreted.

Computational time

The timing summary separates the one-time construction of the genomic relationship matrices from repeated model fitting and prediction across the 150 tasks. This distinction prevents kernel construction from being interpreted as a cost paid independently for every split.

    FUN = mean,

  )

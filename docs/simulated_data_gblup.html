1. Purpose

This module evaluates three GBLUP structures under the six simulated scenarios and the cross-validation partitions defined previously:

  • GBLUP-A: additive genomic effect;
  • GBLUP-AD: additive and dominance genomic effects;
  • GBLUP-ADE: additive, dominance, and additive-by-additive epistatic genomic effects.

Each model is evaluated on the same 25 outer held-out splits within each scenario. The complete workload therefore contains

\[ 6 \times 3 \times 25 = 450 \]

scenario-by-model-by-split fits.

The analysis follows the same information separation used in the original GBLUP-ADE benchmark:

  • phenotype is the fitting response;
  • phenotype values from the 200 outer-assessment individuals are hidden before fitting;
  • genotypes from all 1,000 individuals are available for construction of the genomic relationship matrices;
  • true genetic value is used only after prediction as the primary evaluation target.

3. GBLUP models

3.1 GBLUP-A

The additive model is

\[ \mathbf{y} = \mathbf{1}\mu + \mathbf{a} + \boldsymbol{\varepsilon}, \]

with

\[ \mathbf{a} \sim N(0,\mathbf{A}\sigma_a^2). \]

3.2 GBLUP-AD

The additive-dominance model is

\[ \mathbf{y} = \mathbf{1}\mu + \mathbf{a} + \mathbf{d} + \boldsymbol{\varepsilon}, \]

with

\[ \mathbf{d} \sim N(0,\mathbf{D}\sigma_d^2). \]

3.3 GBLUP-ADE

The third structure extends GBLUP-AD with the additive-by-additive epistatic effect:

\[ \mathbf{y} = \mathbf{1}\mu + \mathbf{a} + \mathbf{d} + \mathbf{e} + \boldsymbol{\varepsilon}, \]

where

\[ \mathbf{e} \sim N(0,\mathbf{E}\sigma_e^2). \]

The residual term in all three models is

\[ \boldsymbol{\varepsilon} \sim N(0,\mathbf{I}\sigma_\varepsilon^2). \]

4. Held-out prediction

For every scenario, model, and outer split, the 200 assessment phenotypes are replaced by NA before model fitting. The fitted model then predicts those individuals from the available genomic information.

The GEBV is stored on the original trait scale and includes the fitted intercept together with the genomic effects represented by the corresponding model:

\[ \widehat{\mathrm{GEBV}}_{\mathrm{A}} = \widehat{\mu} + \widehat{a}, \]

\[ \widehat{\mathrm{GEBV}}_{\mathrm{AD}} = \widehat{\mu} + \widehat{a} + \widehat{d}, \]

and

\[ \widehat{\mathrm{GEBV}}_{\mathrm{ADE}} = \widehat{\mu} + \widehat{a} + \widehat{d} + \widehat{e}. \]

True genetic values are accessed only after the held-out GEBVs have been obtained.

5. Model fitting

The three models use a common fixed intercept and residual variance, while the random-effect structure progressively includes additive, dominance, and epistatic genomic components. In sommer::mmes(), Gu supplies the relevant relationship matrix. Each fit allows 50 iterations and uses a log-likelihood parameter convergence tolerance of 1e-4. For a given scenario and outer partition, the three specifications are:

Each task first identifies its training and assessment individuals. All marker genotypes remain available for genomic covariance calculations, but phenotypes from the 200 assessment individuals are masked before fitting. The model is fitted using the 800 remaining phenotypes, and GEBVs are constructed from the intercept and the relevant genomic effects. Held-out predictions are then compared with simulated true genetic values and observed phenotypes to obtain split-level performance metrics. The individual predictions are retained for subsequent comparisons, with independent fits distributed across workers.

    # Project estimated additive effects to individual-specific values.
    additive_effect <- as.matrix(
      fit$uList[[
        "vsm(ism(id), Gu = A_matrix)"
      ]]
    )

    additive_incidence <- model.matrix(
      ~ id - 1,
      data = dat
    )

    additive <- as.numeric(
      additive_incidence %*%
        additive_effect[
          ,
          1L,
          drop = FALSE
        ]
    )

    # Dominance contributes only to AD and ADE predictions.
    if (
      structure == "AD" ||
      structure == "ADE"
    ) {

      dominance_effect <- as.matrix(
        fit$uList[[
          "vsm(ism(idd), Gu = D_matrix)"
        ]]
      )

      dominance_incidence <- model.matrix(
        ~ idd - 1,
        data = dat
      )

      dominance <- as.numeric(
        dominance_incidence %*%
          dominance_effect[
            ,
            1L,
            drop = FALSE
          ]
      )
    }

    # Add epistatic predictions only for the ADE structure.
    if (structure == "ADE") {

      epistatic_effect <- as.matrix(
        fit$uList[[
          "vsm(ism(ide), Gu = E_matrix)"
        ]]
      )

      epistatic_incidence <- model.matrix(
        ~ ide - 1,
        data = dat
      )

      epistatic <- as.numeric(
        epistatic_incidence %*%
          epistatic_effect[
            ,
            1L,
            drop = FALSE
          ]
      )
    }

    # Sum genetic effects and add the fitted intercept on the trait scale.
    genomic_component <-
      additive +
      dominance +
      epistatic

    intercept <- as.numeric(
      fit$b
    )[
      1L
    ]

    gebv <-
      intercept +
      genomic_component

    predict_seconds <-
      proc.time()[[
        "elapsed"
      ]] -
      prediction_start

    # Extract outcomes for the held-out assessment individuals only.
    observed_test <- phenotype_vector[
      assessment_index
    ]

    true_g_test <- true_g[
      assessment_index,
      scenario_index
    ]

    gebv_test <- gebv[
      assessment_index
    ]

    # Primary assessment: agreement with the known simulated genetic values.
    genetic_pearson <- cor(
      gebv_test,
      true_g_test,
      method = "pearson"
    )

    genetic_spearman <- cor(
      gebv_test,
      true_g_test,
      method = "spearman"
    )

    genetic_rmse <- sqrt(
      mean(
        (
          gebv_test -
          true_g_test
        )^2
      )
    )

    genetic_mae <- mean(
      abs(
        gebv_test -
        true_g_test
      )
    )

    genetic_bias <- mean(
      gebv_test -
        true_g_test
    )

    genetic_slope <- as.numeric(
      coef(
        lm(
          true_g_test ~ gebv_test
        )
      )[2L]
    )

    # Secondary assessment: agreement with the observed phenotypes.
    phenotype_pearson <- cor(
      gebv_test,
      observed_test,
      method = "pearson"
    )

    phenotype_spearman <- cor(
      gebv_test,
      observed_test,
      method = "spearman"
    )

    phenotype_rmse <- sqrt(
      mean(
        (
          gebv_test -
          observed_test
        )^2
      )
    )

    phenotype_mae <- mean(
      abs(
        gebv_test -
        observed_test
      )
    )

    phenotype_bias <- mean(
      gebv_test -
        observed_test
    )

    phenotype_slope <- as.numeric(
      coef(
        lm(
          observed_test ~ gebv_test
        )
      )[2L]
    )

    # Associate each fit with its simulation characteristics.
    meta <- control[
      control$Scenario == scenario,
      ,
      drop = FALSE
    ]

    # Store one row of performance metrics per fitted task.
    result_row <- data.frame(
      Dataset = "simulated",
      Scenario = scenario,
      QTL_N = meta$QTL_N,
      H2_nominal = meta$H2_nominal,
      Repetition = task$Repetition,
      Fold = task$OuterFold,
      SplitID = task$SplitID,
      TaskID = task$TaskID,
      Model = task$Model,
      Structure = structure,
      N_train = length(
        analysis_index
      ),
      N_test = length(
        assessment_index
      ),
      Genetic_Pearson =
        genetic_pearson,
      Genetic_Spearman =
        genetic_spearman,
      Genetic_RMSE =
        genetic_rmse,
      Genetic_MAE =
        genetic_mae,
      Genetic_Bias =
        genetic_bias,
      Genetic_Slope =
        genetic_slope,
      Phenotype_Pearson =
        phenotype_pearson,

      Phenotype_RMSE =
        phenotype_rmse,
      Phenotype_MAE =

      Phenotype_Slope =
        phenotype_slope,
      Fit_seconds =
        fit_seconds,
      Predict_seconds =
        predict_seconds,
      stringsAsFactors = FALSE

    # Store 200 held-out predictions and their additive/AD/ADE components.
    prediction_rows <- data.frame(
      Dataset = "simulated",

      QTL_N = meta$QTL_N,
      H2_nominal = meta$H2_nominal,

6. Evaluation metrics

The true genetic value is the primary target because it is known in the simulation and directly measures recovery of the simulated genetic signal.

The phenotype is retained as a secondary target because it includes the genetic signal together with residual variation.

Held-out predictive performance is summarized using the following metrics:

  • Pearson correlation: linear association between GEBV and the target;
  • Spearman correlation: rank association between GEBV and the target;
  • RMSE: prediction error on the original scale;
  • MAE: mean absolute prediction error on the original scale.

Bias and calibration slope are complementary measures. Bias is mean(prediction - target), and calibration slope is the coefficient of prediction in lm(target ~ prediction). R-squared is not used.

No evaluation target is used during model fitting.

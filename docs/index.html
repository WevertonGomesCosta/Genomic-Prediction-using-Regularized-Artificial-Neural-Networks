English

Start here

This website documents a reproducible study of genomic prediction using regularized artificial neural networks and a GBLUP-ADE genomic mixed-model benchmark.

The project combines controlled simulated genomic data with real longitudinal Coffea arabica data. Its central question is whether L1 and L2 weight regularization improves predictive performance and generalization relative to an unregularized ANN and GBLUP-ADE when all methods are evaluated under matched validation designs.

Project at a glance

The genomic-prediction comparison includes:

  • GBLUP-ADE with additive, dominance, and epistatic genomic effects;
  • ANN without L1/L2 regularization;
  • ANN-L1;
  • ANN-L2;
  • ANN-L1+L2.

The simulated branch uses known true genetic values as an independent evaluation target. The real-data branch derives individual genotypic BLUPs from the complete longitudinal phenotypic dataset before integration with the genomic marker data.

Recommended reading path

The simulated-data workflow is organized as:

  1. Data audit — source-data preparation, integrity checks, genotype and phenotype structure, genetic-map information, QTL information, and simulation-scenario summaries.
  2. Validation design — common outer and inner validation partitions shared by all competing models.
  3. Parallel genomic-prediction branches:
    • GBLUP-ADE
    • Regularized ANN
  4. Model comparison — terminal comparison of saved predictions and performance summaries under the common validation design.

The real-data workflow is defined as:

  1. real_data_phenotype.Rmd — longitudinal phenotypic organization, descriptive analysis, REML mixed-model fitting with sommer, variance components, and individual genotypic BLUPs;
  2. real_data_audit.Rmd — integration of phenotypic BLUPs with geno_real.rds, individual alignment, marker quality control, and construction of the common real-data object;
  3. real_data_validation.Rmd — shared validation design;
  4. parallel GBLUP-ADE and ANN modeling branches;
  5. real_data_comparison.Rmd — terminal task-matched model comparison.

Validation scope

Outer-assessment responses are excluded from model fitting and model selection. ANN hyperparameter and epoch selection are restricted to the corresponding outer-analysis sample, and all competing methods are evaluated on matched held-out individuals.

For simulated data, true genetic values are excluded from fitting and selection and are used only for independent predictive assessment.

For real data, genomic prediction uses the individual genotypic BLUPs obtained from the longitudinal phenotypic mixed model. Held-out genomic predictions should not be interpreted as final breeding values from a model refitted with all available responses.

Reproducibility and project information

The source analyses are stored under analysis/, derived analytical objects under output/, and the rendered workflowr site under docs/. Package dependencies are recorded with renv.

The repository README documents the project structure and reconstruction principles. Detailed source-data and output contracts are documented in the corresponding repository directories.

Português

Comece aqui

Este site documenta um estudo reprodutível de predição genômica utilizando redes neurais artificiais regularizadas e um modelo misto genômico GBLUP-ADE como referência de comparação.

O projeto combina dados genômicos simulados controlados com dados longitudinais reais de Coffea arabica. A pergunta central é se a regularização L1 e L2 dos pesos melhora o desempenho preditivo e a generalização em relação a uma ANN não regularizada e ao GBLUP-ADE quando todos os métodos são avaliados sob desenhos de validação equivalentes.

Projeto em resumo

A comparação de predição genômica inclui:

  • GBLUP-ADE com efeitos genômicos aditivos, de dominância e epistáticos;
  • ANN sem regularização L1/L2;
  • ANN-L1;
  • ANN-L2;
  • ANN-L1+L2.

O ramo simulado utiliza valores genéticos verdadeiros conhecidos como alvo independente de avaliação. O ramo de dados reais obtém BLUPs genotípicos individuais a partir do conjunto fenotípico longitudinal completo antes da integração com os dados de marcadores genômicos.

Ordem recomendada de leitura

O fluxo de dados simulados está organizado em:

  1. Auditoria dos dados — preparação dos dados-fonte, verificações de integridade, estrutura genotípica e fenotípica, mapa genético, informações de QTL e resumos dos cenários de simulação.
  2. Desenho de validação — partições externas e internas comuns a todos os modelos concorrentes.
  3. Ramos paralelos de predição genômica:
    • GBLUP-ADE
    • ANN regularizadas
  4. Comparação dos modelos — comparação terminal das predições e dos resumos de desempenho sob o desenho comum de validação.

O fluxo de dados reais é definido como:

  1. real_data_phenotype.Rmd — organização fenotípica longitudinal, análises descritivas, ajuste do modelo misto por REML com sommer, componentes de variância e BLUPs genotípicos individuais;
  2. real_data_audit.Rmd — integração dos BLUPs fenotípicos com geno_real.rds, alinhamento dos indivíduos, controle de qualidade dos marcadores e construção do objeto comum dos dados reais;
  3. real_data_validation.Rmd — desenho comum de validação;
  4. ramos paralelos de modelagem GBLUP-ADE e ANN;
  5. real_data_comparison.Rmd — comparação terminal dos modelos em tarefas correspondentes.

Escopo da validação

As respostas dos indivíduos de avaliação externa são excluídas do ajuste e da seleção dos modelos. A seleção de hiperparâmetros e de épocas das ANN é restrita à respectiva amostra de análise externa, e todos os métodos concorrentes são avaliados nos mesmos indivíduos mantidos fora do ajuste.

Nos dados simulados, os valores genéticos verdadeiros são excluídos do ajuste e da seleção e são utilizados apenas na avaliação preditiva independente.

Nos dados reais, a predição genômica utiliza os BLUPs genotípicos individuais obtidos do modelo misto fenotípico longitudinal. As predições genômicas obtidas fora da amostra não devem ser interpretadas como valores genéticos finais provenientes de um modelo reajustado com todas as respostas disponíveis.

Reprodutibilidade e informações do projeto

As análises-fonte estão em analysis/, os objetos analíticos derivados em output/ e o site workflowr renderizado em docs/. As dependências dos pacotes são registradas com renv.

O README do repositório documenta a estrutura do projeto e os princípios de reconstrução. Os contratos detalhados dos dados-fonte e das saídas estão documentados nos respectivos diretórios do repositório.

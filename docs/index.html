English

Start here

This website documents a reproducible study of genomic prediction comparing three GBLUP genomic mixed models with four regularized artificial neural-network configurations.

The project combines controlled simulated genomic data with real longitudinal Coffea arabica data. Its central comparison includes GBLUP-A, GBLUP-AD, GBLUP-ADE, and four ANN configurations evaluated under matched validation designs, with specific interest in the effect of L1 and L2 weight regularization relative to the unregularized ANN.

Project at a glance

The genomic-prediction comparison includes:

  • GBLUP-A;
  • GBLUP-AD;
  • GBLUP-ADE;
  • ANN without L1/L2 regularization;
  • ANN-L1;
  • ANN-L2;
  • ANN-L1+L2.

Metric and tuning contract

ANN tuning uses mean inner-assessment RMSE as the primary performance criterion and mean inner-assessment Pearson correlation as the only performance tie-breaker. No other predictive metric is calculated, stored, or used in ANN tuning.

Held-out evaluation uses Pearson, Spearman, RMSE, and MAE as common predictive metrics. Bias and calibration slope are secondary diagnostics. R-squared is not used.

The simulated branch uses known true genetic values as an independent evaluation target. The real-data branch derives individual BLUPs from the complete longitudinal phenotypic dataset before integration with the genomic marker data.

Recommended reading path

The simulated-data workflow is organized as:

  1. Data audit — source-data preparation, integrity checks, genotype and phenotype structure, genetic-map information, QTL information, and simulation-scenario summaries.
  2. Validation design — common outer and inner validation partitions shared by all competing models.
  3. Parallel genomic-prediction branches:
    • GBLUP-A / GBLUP-AD / GBLUP-ADE
    • Regularized ANN
  4. Model comparison — terminal comparison of saved predictions and performance summaries under the common validation design.

The real-data workflow follows this sequence:

  1. Longitudinal phenotypes and BLUPs — phenotypic organization, descriptive analysis, REML mixed-model fitting, variance components, and individual BLUPs.
  2. Genomic data audit — integration of phenotypic BLUPs with geno_real.rds, individual alignment, marker quality control, and preparation of the common genomic object.
  3. Validation design — shared outer and inner validation partitions.
  4. Parallel genomic-prediction branches:
    • GBLUP-A / GBLUP-AD / GBLUP-ADE
    • Regularized ANN
  5. Model comparison — matched evaluation of saved genomic predictions and ranking results.

Validation scope

Outer-assessment responses are excluded from model fitting and model selection. ANN hyperparameter and epoch selection are restricted to the corresponding outer-analysis sample, and all competing methods are evaluated on matched held-out individuals.

For simulated data, true genetic values are excluded from fitting and selection and are used only for independent predictive assessment.

For real data, genomic prediction uses the individual BLUPs obtained from the longitudinal phenotypic mixed model. Held-out genomic predictions should not be interpreted as final breeding values from a model refitted with all available responses.

Reproducibility and project information

The source analyses are stored under analysis/, derived analytical objects under output/, and the rendered workflowr site under docs/. Package dependencies are recorded with renv.

The repository README documents the project structure and reconstruction principles. Detailed source-data and output contracts are documented in the corresponding repository directories.

Comece aqui

Este site documenta um estudo reprodutível de predição genômica comparando três modelos mistos genômicos GBLUP com quatro configurações de redes neurais artificiais regularizadas.

O projeto combina dados genômicos simulados controlados com dados longitudinais reais de Coffea arabica. A comparação central inclui GBLUP-A, GBLUP-AD, GBLUP-ADE e quatro configurações de ANN sob desenhos de validação equivalentes, com interesse específico no efeito das regularizações L1 e L2 em relação à ANN não regularizada.

Projeto em resumo

A comparação de predição genômica inclui:

  • GBLUP-A;
  • GBLUP-AD;
  • GBLUP-ADE;
  • ANN sem regularização L1/L2;
  • ANN-L1;
  • ANN-L2;
  • ANN-L1+L2.

Contrato de métricas e tuning

O tuning das ANN utiliza RMSE médio na avaliação interna como critério primário de desempenho e correlação de Pearson média na avaliação interna como único desempate de desempenho. Nenhuma outra métrica preditiva é calculada, armazenada ou utilizada no tuning das ANN.

A avaliação externa utiliza Pearson, Spearman, RMSE e MAE como métricas preditivas comuns. Viés e inclinação de calibração são diagnósticos secundários. R-quadrado não é utilizado.

O ramo simulado utiliza valores genéticos verdadeiros conhecidos como alvo independente de avaliação. O ramo de dados reais obtém BLUPs individuais a partir do conjunto fenotípico longitudinal completo antes da integração com os dados de marcadores genômicos.

Ordem recomendada de leitura

O fluxo de dados simulados está organizado em:

  1. Auditoria dos dados — preparação dos dados-fonte, verificações de integridade, estrutura genotípica e fenotípica, mapa genético, informações de QTL e resumos dos cenários de simulação.
  2. Desenho de validação — partições externas e internas comuns a todos os modelos concorrentes.
  3. Ramos paralelos de predição genômica:
    • GBLUP-A / GBLUP-AD / GBLUP-ADE
    • ANN regularizadas
  4. Comparação dos modelos — comparação terminal das predições e dos resumos de desempenho sob o desenho comum de validação.

O fluxo de dados reais segue esta sequência:

  1. Fenótipos longitudinais e BLUPs — organização fenotípica, análises descritivas, ajuste do modelo misto por REML, componentes de variância e BLUPs individuais.
  2. Auditoria dos dados genômicos — integração dos BLUPs com geno_real.rds, alinhamento dos indivíduos, controle de qualidade dos marcadores e preparação do objeto genômico comum.
  3. Desenho de validação — partições externas e internas compartilhadas.
  4. Ramos paralelos de predição genômica:
    • GBLUP-A / GBLUP-AD / GBLUP-ADE
    • ANN regularizadas
  5. Comparação dos modelos — avaliação correspondente das predições genômicas e dos resultados de classificação.

Escopo da validação

As respostas dos indivíduos de avaliação externa são excluídas do ajuste e da seleção dos modelos. A seleção de hiperparâmetros e de épocas das ANN é restrita à respectiva amostra de análise externa, e todos os métodos concorrentes são avaliados nos mesmos indivíduos mantidos fora do ajuste.

Nos dados simulados, os valores genéticos verdadeiros são excluídos do ajuste e da seleção e são utilizados apenas na avaliação preditiva independente.

Nos dados reais, a predição genômica utiliza os BLUPs individuais obtidos do modelo misto fenotípico longitudinal. As predições genômicas obtidas fora da amostra não devem ser interpretadas como valores genéticos finais provenientes de um modelo reajustado com todas as respostas disponíveis.

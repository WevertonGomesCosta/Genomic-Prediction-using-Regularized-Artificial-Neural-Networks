Purpose

This analysis performs the canonical audit and preprocessing of the simulated genomic dataset before any genomic prediction model is fitted.

The audit evaluates file integrity, dimensional consistency, genotype coding, genetic map structure, simulation scenarios, quantitative trait loci (QTL), phenotypic and true genetic values, realized heritability, parental genotypes, marker frequencies, duplicate observations, and linkage disequilibrium.

No genomic prediction model is fitted in this document.

How to read this audit

Each section explains a property required before genomic prediction and shows the data summaries that are useful for scientific interpretation. Internal integrity checks still classify conditions as PASS, WARNING, or BLOCKED, but the complete operational checklist is written to the audit output rather than repeated throughout the public page. A BLOCKED condition prevents creation of the canonical modeling object, while scientifically relevant warnings are discussed directly in the section where they arise.

Simulation control file

The control file defines the six simulated scenarios. The code below reads each scenario block, extracts the prespecified metadata and QTL list, and preserves the original numeric values while normalizing only the malformed whitespace in one source key required for parsing.

control_raw <- readLines(
  file.path(data_dir, "controlegenetico#1.dat"),
  warn = FALSE
)

control_ascii <- iconv(
  control_raw,
  from = "latin1",
  to = "ASCII//TRANSLIT",
  sub = ""
)

# The original control file contains an internal tab in the C1 key
# "Escal\ta". Normalize whitespace inside keys only; numeric values are
# retained exactly as stored in the source file.
normalize_control_key <- function(x) {
  key <- sub(",.*$", "", x)
  key <- trimws(key)
  key <- gsub("[[:space:]]+", "", key)
  tolower(key)
}

control_keys <- vapply(
  control_ascii,
  normalize_control_key,
  character(1)
)

scenario_start <- which(control_keys == "variavel")

if (length(scenario_start) != 6L) {
  add_audit(
    "Simulation control blocks",
    "BLOCKED",
    paste("Expected 6 scenario blocks; found", length(scenario_start))
  )
  stop("Unexpected number of scenario blocks in control file.")
}

scenario_end <- c(
  scenario_start[-1L] - 1L,
  length(control_ascii)
)

scale_source_lines <- grep(
  "^\\s*Escal",
  control_ascii,
  value = TRUE,
  ignore.case = TRUE
)

scale_source_keys <- trimws(
  sub(",.*$", "", scale_source_lines)
)

scale_key_has_internal_whitespace <- any(
  grepl("[[:space:]]", scale_source_keys)
)

add_audit(
  "Simulation-control key formatting",
  if (scale_key_has_internal_whitespace) "WARNING" else "PASS",
  if (scale_key_has_internal_whitespace) {
    paste(
      "The source control file contains internal whitespace in the C1",
      "Scale key (Escal<tab>a). Key whitespace was normalized for parsing;",
      "the stored numeric value was not altered."
    )
  } else {
    "Control-file keys required no internal-whitespace normalization."
  }
)

extract_control_value <- function(block, key) {
  block_keys <- vapply(
    block,
    normalize_control_key,
    character(1)
  )

  target_key <- normalize_control_key(
    paste0(key, ",")
  )

  hit <- which(block_keys == target_key)

  if (length(hit) == 0L) {
    return(NA_real_)
  }

  value_text <- trimws(
    sub("^[^,]*,", "", block[hit[1L]])
  )

  suppressWarnings(
    as.numeric(value_text)
  )
}

control_rows <- vector("list", length(scenario_start))
qtl_lists <- vector("list", length(scenario_start))

Genotype quality control

This section checks whether the simulated genotype matrix has the structural properties required for the downstream genomic analyses. The diagnostics have different roles:

  • missing genotypes identify unavailable marker calls; missing cells are blocking here because the canonical simulated dataset is expected to be complete;
  • duplicate individuals identify identical complete genotype profiles among progeny and are treated as blocking because they would violate the expected individual-level structure of this simulated population;
  • duplicate markers identify marker columns with identical genotype profiles across all individuals;
  • monomorphic markers identify loci with no observed genotype variation and therefore no information for distinguishing individuals;
  • minor allele frequency (MAF) summarizes the frequency of the less common allele at each marker and provides a marker-level description of segregation;
  • heterozygosity records the proportion of heterozygous individuals at each marker;
  • the overall 0/1/2 genotype proportions are compared with the expected F2 segregation pattern of approximately 1:2:1.

These checks audit the known simulated population rather than impose a generic quality-control pipeline for empirical genomic data. The numerical criteria below are therefore part of this simulation audit. Non-blocking departures are reported as WARNING and retained explicitly instead of being filtered silently from the canonical genotype matrix.

Serialized map reference

Linkage disequilibrium

Linkage disequilibrium (LD) is used here to describe how strongly marker genotypes remain associated as genetic-map distance increases. For each marker pair, the audit uses \(r^2\), the squared correlation between their standardized 0/1/2 genotype codings. Larger values indicate stronger marker association, whereas values closer to zero indicate weaker association.

The analysis separates two complementary comparisons:

  • within-linkage-group LD is evaluated for marker pairs separated by fixed map distances from 0.5 to 200 cM. In a recombining population, linked markers are generally expected to show stronger association at short distances and weaker association as map distance increases;
  • an interchromosomal reference is obtained from 5,000 randomly sampled marker pairs belonging to different linkage groups. Because these pairs are not linked on the same chromosome, their mean \(r^2\) provides a background reference for interpreting residual association among widely separated markers within a linkage group.

The purpose is descriptive and diagnostic rather than a marker-filtering step. In particular, persistence of elevated within-linkage-group LD at 100-200 cM relative to the interchromosomal reference is recorded as a WARNING about the simulator’s long-distance recombination behavior. It is not interpreted by itself as evidence of corrupted data, and it does not cause markers to be removed from the canonical genotype matrix.

if (monomorphic_markers == 0L) {
  geno_scaled <- scale(
    geno_012,
    center = TRUE,
    scale = TRUE
  )

  pair_r2 <- function(i, j, z, block_size = 500L) {
    stopifnot(length(i) == length(j))

    result <- numeric(length(i))

    if (length(i) == 0L) {
      return(result)
    }

    block_start <- seq(
      1L,
      length(i),
      by = block_size
    )

    for (start in block_start) {
      end <- min(
        start + block_size - 1L,
        length(i)
      )

      b <- start:end

      r <- colSums(
        z[, i[b], drop = FALSE] *
          z[, j[b], drop = FALSE]
      ) / (nrow(z) - 1)

      result[b] <- r^2
    }

    result
  }

  ld_distances <- c(
    0.5,
    1,
    2.5,
    5,
    10,
    25,
    50,
    100,
    200
  )

  ld_rows <- vector(
    "list",
    length(ld_distances)
  )

  for (d in seq_along(ld_distances)) {
    distance <- ld_distances[d]
    r2_all <- numeric()

    for (lg in sort(unique(genetic_map$LG))) {
      idx <- which(genetic_map$LG == lg)

      idx <- idx[
        order(genetic_map$Position_cM[idx])
      ]

      pos <- genetic_map$Position_cM[idx]

      target <- match(
        pos + distance,
        pos
      )

      keep <- !is.na(target)

      if (any(keep)) {
        i <- idx[keep]
        j <- idx[target[keep]]

        r2_all <- c(
          r2_all,
          pair_r2(
            i,
            j,
            geno_scaled
          )
        )
      }
    }

    ld_rows[[d]] <- data.frame(
      Distance_cM = distance,
      Pairs = length(r2_all),
      Mean_r2 = mean(r2_all),
      Median_r2 = median(r2_all)
    )
  }

  ld_summary <- do.call(
    rbind,
    ld_rows
  )

  set.seed(SEED_GLOBAL + 101L)

  n_inter_pairs <- 5000L

  inter_i <- sample(
    seq_len(ncol(geno_012)),
    n_inter_pairs,
    replace = TRUE
  )

  inter_j <- sample(
    seq_len(ncol(geno_012)),
    n_inter_pairs,
    replace = TRUE
  )

  same_lg <- genetic_map$LG[inter_i] ==
    genetic_map$LG[inter_j]

  while (any(same_lg)) {
    inter_j[same_lg] <- sample(
      seq_len(ncol(geno_012)),
      sum(same_lg),
      replace = TRUE
    )

    same_lg <- genetic_map$LG[inter_i] ==
      genetic_map$LG[inter_j]
  }

  inter_r2 <- pair_r2(
    inter_i,
    inter_j,
    geno_scaled
  )

  interchromosomal_ld <- data.frame(
    Distance_cM = NA_real_,
    Pairs = length(inter_r2),
    Mean_r2 = mean(inter_r2),
    Median_r2 = median(inter_r2)
  )

  knitr::kable(
    ld_summary,
    digits = 5,
    caption = "Within-linkage-group LD decay"
  )

  knitr::kable(
    interchromosomal_ld,
    digits = 5,
    caption = "Interchromosomal LD reference"
  )

  plot(
    ld_summary$Distance_cM,
    ld_summary$Mean_r2,
    type = "b",
    xlab = "Map distance (cM)",
    ylab = expression(mean(r^2)),
    main = "Linkage disequilibrium decay"
  )

  abline(
    h = interchromosomal_ld$Mean_r2,
    lty = 2
  )

  short_ld <- ld_summary$Mean_r2[
    ld_summary$Distance_cM == 0.5
  ]

  medium_ld <- ld_summary$Mean_r2[
    ld_summary$Distance_cM == 10
  ]

  ld_50 <- ld_summary$Mean_r2[
    ld_summary$Distance_cM == 50
  ]

  ld_100 <- ld_summary$Mean_r2[
    ld_summary$Distance_cM == 100
  ]

  ld_200 <- ld_summary$Mean_r2[
    ld_summary$Distance_cM == 200
  ]

  ld_decay_ok <-
    short_ld > medium_ld &&
    medium_ld > ld_50 &&
    ld_50 > interchromosomal_ld$Mean_r2 &&
    interchromosomal_ld$Mean_r2 < 0.02

  add_audit(
    "Short-to-medium distance LD decay",
    if (ld_decay_ok) "PASS" else "WARNING",
    paste(
      "Mean r2 at 0.5, 10, and 50 cM:",
      paste(
        round(c(short_ld, medium_ld, ld_50), 4),
        collapse = ", "
      ),
      "; interchromosomal mean r2:",
      round(interchromosomal_ld$Mean_r2, 5)
    )
  )

  long_distance_plateau <-
    is.finite(ld_100) &&
    is.finite(ld_200) &&
    ld_100 > 0.05 &&
    ld_200 > 0.05 &&
    ld_100 > 10 * interchromosomal_ld$Mean_r2 &&
    ld_200 > 10 * interchromosomal_ld$Mean_r2

  add_audit(
    "Long-distance LD behavior",
    if (long_distance_plateau) "WARNING" else "PASS",
    paste(
      "Mean r2 at 50, 100, and 200 cM:",
      paste(
        round(c(ld_50, ld_100, ld_200), 4),
        collapse = ", "
      ),
      "; interchromosomal mean r2:",
      round(interchromosomal_ld$Mean_r2, 5),
      if (long_distance_plateau) {
        paste(
          ". LD declines strongly up to 50 cM but remains elevated at",
          "100-200 cM relative to the interchromosomal reference.",
          "This is documented as a property requiring interpretation of",
          "the simulator's long-distance recombination behavior, not as",
          "evidence of data corruption."
        )
      } else {
        ". No marked long-distance LD plateau was detected."
      }
    )
  )

  rm(geno_scaled)
  invisible(gc())
} else {
  ld_summary <- data.frame()
  interchromosomal_ld <- data.frame()

  add_audit(
    "Short-to-medium distance LD decay",
    "BLOCKED",
    "LD calculation was blocked because monomorphic markers were detected."
  )

  add_audit(
    "Long-distance LD behavior",
    "BLOCKED",
    "LD calculation was blocked because monomorphic markers were detected."
  )
}

The LD audit distinguishes the expected short-to-medium distance decay from the behavior observed at the longest intrachromosomal distances. If LD remains substantially elevated at 100-200 cM relative to the interchromosomal reference, this is recorded as a WARNING. The warning does not alter or filter the genotype matrix; it documents a feature that should be considered when interpreting the simulator’s recombination process.

Interpretation of the simulation scenarios

The six scenarios constitute a complexity gradient, rather than a complete factorial experiment between QTL number and heritability.

The nominal scenarios are:

C4 120 0.5 0.5 2 100
C5 240 0.3 0.5 2 100
C6 480 0.3 0.5 2 100

Direct comparisons of QTL-number complexity while nominal heritability is held constant are therefore naturally defined within the following pairs:

  • C1 versus C2 at nominal \(H^2 = 0.7\);
  • C3 versus C4 at nominal \(H^2 = 0.5\);
  • C5 versus C6 at nominal \(H^2 = 0.3\).

Across all six scenarios simultaneously, QTL number increases while nominal heritability decreases. Consequently, a global trend across C1-C6 must not be interpreted as an isolated causal effect of QTL number or heritability.

The simulator control file records Model = 2 for all six scenarios. This numeric field is retained here as part of the data provenance, but its biological meaning is not inferred from the code value alone in this audit. The downstream GBLUP-ADE benchmark is a separate prespecified modeling choice: its additive, dominance, and epistatic components are defined and justified in the GBLUP module rather than being established solely by Model = 2.

Internal integrity status

The detailed checklist is evaluated before the canonical object is created, but only its overall classification is needed in the reader-facing narrative.

The internal checks classify this preprocessing stage as PASS WITH WARNINGS. The complete checklist is retained in simulated_audit_summary.csv rather than reproduced on this page. Scientifically relevant warnings, including the linkage-disequilibrium behavior discussed above, remain explicit in the narrative and do not invalidate the dataset unless a corresponding condition is classified as BLOCKED.

Canonical preprocessed object

The canonical preprocessed object is generated only when no blocking audit failure is present. The saved preprocessed_simulated_common.rds acts as the shared data contract for the downstream validation and modeling modules, so those modules consume the same audited representation instead of independently re-reading and re-interpreting the raw simulator files.

Its components have distinct scientific roles:

  • phenotype contains the observed response values available for model fitting within the appropriate analysis subsets;
  • genotype_m101 is the canonical -1/0/1 genotype representation used by the downstream genomic prediction workflows, while genotype_012 is retained as the validated source representation;
  • metadata$row_identifier preserves the row-position identity contract used to align individuals across phenotypes, genotypes, validation splits, and predictions;
  • true_genetic_value is retained for held-out predictive evaluation only. It is not used to generate validation folds, tune ANN hyperparameters, select training duration, or fit the predictive models;
  • map, scenario, QTL, marker-QC, and LD components preserve the audited simulation structure and provenance for downstream checks and interpretation. Their presence in the common object does not make them additional response variables or automatic model predictors.

The next module uses this audited object to construct the frozen nested cross-validation design. The GBLUP-ADE and ANN branches then consume that common data contract together with the same frozen validation design, preserving individual and task alignment across the parallel modeling workflows.

The resulting preprocessed_simulated_common.rds is the shared preprocessed data contract passed to the validation module and, from there, to both parallel modeling branches. The detailed CSV audit files remain available for reproducibility and maintenance without occupying the main scientific narrative.

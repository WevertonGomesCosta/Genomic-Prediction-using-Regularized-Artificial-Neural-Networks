1. Objective

This analysis performs the canonical audit and preprocessing of the simulated genomic dataset before any genomic prediction model is fitted.

The audit evaluates file integrity, dimensional consistency, genotype coding, genetic map structure, simulation scenarios, quantitative trait loci (QTL), phenotypic and true genetic values, realized heritability, parental genotypes, marker frequencies, duplicate observations, and linkage disequilibrium.

No genomic prediction model is fitted in this document.

1.1 How to read this module

Each section explains a property required before genomic prediction and shows the data summaries that are useful for scientific interpretation. The audit reports observed dimensions, codes, distributions, frequencies, and diagnostics directly. The reader can therefore inspect what is present in the simulated data without translating boolean guards into scientific meaning.

8. Genotype diagnostics

8.1 Marker and individual diagnostics

This section checks whether the simulated genotype matrix has the structural properties required for the downstream genomic analyses. The diagnostics have different roles:

  • missing genotypes identify unavailable marker calls; missing cells are blocking here because the canonical simulated dataset is expected to be complete;
  • duplicate individuals identify identical complete genotype profiles among progeny and are treated as blocking because they would violate the expected individual-level structure of this simulated population;
  • duplicate markers identify marker columns with identical genotype profiles across all individuals;
  • monomorphic markers identify loci with no observed genotype variation and therefore no information for distinguishing individuals;
  • minor allele frequency (MAF) summarizes the frequency of the less common allele at each marker and provides a marker-level description of segregation;
  • heterozygosity records the proportion of heterozygous individuals at each marker;
  • the overall 0/1/2 genotype proportions are compared with the expected F2 segregation pattern of approximately 1:2:1.

These checks audit the known simulated population rather than impose a generic quality-control pipeline for empirical genomic data. The numerical criteria below are therefore part of this simulation audit. Observed departures are retained explicitly instead of being filtered silently from the canonical genotype matrix.

10. Linkage disequilibrium

Linkage disequilibrium (LD) is used here to describe how strongly marker genotypes remain associated as genetic-map distance increases. For each marker pair, the audit uses \(r^2\), the squared correlation between their standardized 0/1/2 genotype codings. Larger values indicate stronger marker association, whereas values closer to zero indicate weaker association.

10.1 LD comparisons

The analysis separates two complementary comparisons:

  • within-linkage-group LD is evaluated for marker pairs separated by fixed map distances from 0.5 to 200 cM. In a recombining population, linked markers are generally expected to show stronger association at short distances and weaker association as map distance increases;
  • an interchromosomal reference is obtained from 5,000 randomly sampled marker pairs belonging to different linkage groups. Because these pairs are not linked on the same chromosome, their mean \(r^2\) provides a background reference for interpreting residual association among widely separated markers within a linkage group.

The purpose is descriptive and diagnostic rather than a marker-filtering step. In particular, persistence of elevated within-linkage-group LD at 100-200 cM relative to the interchromosomal reference is reported explicitly as a feature of the simulator’s long-distance recombination behavior. It is not interpreted by itself as evidence of corrupted data, and it does not cause markers to be removed from the canonical genotype matrix.

# Standardize marker genotypes before calculating correlations.
geno_scaled <- scale(
  geno_012,
  center = TRUE,
  scale = TRUE
)

# Calculate r-squared for selected marker pairs.
pair_r2 <- function(
  i,
  j,
  z,
  block_size = 500L
) {
  result <- numeric(length(i))

  n_blocks <- ceiling(
    length(i) / block_size
  )

  for (block in seq_len(n_blocks)) {
    start <- (block - 1L) * block_size + 1L
    end <- min(
      start + block_size - 1L,
      length(i)
    )

    b <- start:end

    r <- colSums(
      z[, i[b], drop = FALSE] *
        z[, j[b], drop = FALSE]
    ) / (nrow(z) - 1)

    result[b] <- r^2
  }

  result
}

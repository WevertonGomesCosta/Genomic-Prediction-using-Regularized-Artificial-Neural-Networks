1. Purpose

This module defines the nested cross-validation procedure used by every genomic-prediction method fitted to the real Coffea arabica population. The partitions are created before model fitting and are reused unchanged by GBLUP-A, GBLUP-AD, GBLUP-ADE, and all ANN variants.

Cross-validation follows four specifications:

  • Repeated outer cross-validation: 5 repetitions of 5 outer folds provide 25 held-out evaluations.
  • Nested inner cross-validation: each outer analysis set is divided into 4 inner folds for ANN model selection.
  • Common partitions: the same outer and inner assignments are reused for Cer, BM, LP, GBLUP-A, GBLUP-AD, GBLUP-ADE, and all ANN configurations.
  • Information separation: BLUP values, genomic marker values, and model identity do not participate in fold generation.

Throughout this module, analysis set denotes individuals available for model development at the current validation level, whereas assessment set denotes individuals held out for evaluation at that level.

The functional workflow is:

receive aligned individuals and genomic inputs → fix the validation design → generate repeated outer assessment folds → verify outer-fold coverage → create inner folds within each outer analysis set → verify that held-out outer individuals never enter inner tuning → document the partition scope → export the shared validation contract for GBLUP and ANN.

Phenotypic BLUPs have already been estimated and aligned with genotypes in the preceding modules. The cross-validation folds are generated by random sampling of individual identifiers using deterministic seeds. Every repetition reshuffles the 195 individuals, without separating progenies or evaluation environments. Phenotypic targets and SNP values do not determine fold membership.

The individual BLUP targets were estimated in R01 using the available phenotypic records before these partitions were created. They are not re-estimated within each fold. Accordingly, the held-out assessments evaluate genomic predictions of precomputed BLUP targets, not predictions of phenotypic observations withheld from the initial BLUP estimation.

4. Repeated outer cross-validation

In each repetition, the 195 individuals are randomly shuffled and divided into five folds of equal size. Because 195 is exactly divisible by five, every outer assessment fold contains 39 individuals and the remaining 156 individuals form the corresponding outer analysis set.

4.1 Outer fold assignments

outer_assignment_list <- vector(
  "list",
  N_OUTER_REPEATS
)

outer_splits <- list()

for (rep_id in seq_len(N_OUTER_REPEATS)) {

  set.seed(
    SEED_GLOBAL + rep_id
  )

  shuffled_ids <- sample(
    ids,
    size = length(ids),
    replace = FALSE
  )

  assigned_folds <- rep(
    seq_len(N_OUTER_FOLDS),
    each = length(ids) / N_OUTER_FOLDS
  )

  assignment <- data.frame(
    Repetition = rep_id,
    ID = shuffled_ids,
    OuterFold = assigned_folds,
    stringsAsFactors = FALSE
  )

  assignment <- assignment[
    order(assignment$ID),
    ,
    drop = FALSE
  ]

  rownames(
    assignment
  ) <- NULL

  assignment$SplitID <- sprintf(
    "R%02d_F%02d",
    assignment$Repetition,
    assignment$OuterFold
  )

  outer_assignment_list[[rep_id]] <- assignment

  for (outer_fold in seq_len(N_OUTER_FOLDS)) {

    split_id <- sprintf(
      "R%02d_F%02d",
      rep_id,
      outer_fold
    )

    assessment_ids <- assignment$ID[
      assignment$OuterFold == outer_fold
    ]

    analysis_ids <- ids[
      !ids %in% assessment_ids
    ]

    outer_splits[[split_id]] <- list(
      split_id = split_id,
      repetition = rep_id,
      outer_fold = outer_fold,
      analysis_ids = analysis_ids,
      assessment_ids = assessment_ids
    )
  }
}

Across all outer partitions, every individual is assessed once in each repetition and five times in total. Thus, within each repetition, the five assessment folds are disjoint and together cover the full population. The repeated assessments reuse individuals across repetitions; the 25 outer splits are not 25 independent external populations.

5. Nested inner cross-validation

Each outer analysis set contains 156 individuals. Within each outer split, these individuals are randomly shuffled and divided into four equal inner folds.

Each inner assessment set therefore contains 39 individuals, while the remaining 117 individuals form the corresponding inner analysis set. The outer assessment individuals do not participate in inner partition generation.

9. Synthesis and transition to genomic prediction

This module establishes which individuals are used for model fitting, selection, and held-out assessment in each repeated cross-validation split. No genomic-prediction model is fitted here. The same partitions are delivered to every downstream method, preserving a paired comparison across models.

The persisted real_cv_design.rds contains the individual IDs, outer and inner assignment tables, explicit split vectors, fixed validation settings, and coverage and overlap checks. The companion files real_outer_assignments.csv, real_inner_assignments.csv, and real_validation_summary.csv allow independent inspection of the design.

The primary model comparison uses the same 25 outer assessment sets for GBLUP-A, GBLUP-AD, GBLUP-ADE, and every ANN configuration. ANN model selection is restricted to the four inner folds of each outer analysis set. No phenotypic or genomic values determine the partition membership.

The next modules fit GBLUP-A / AD / ADE and regularized ANN with this fixed design. Their predictive metrics describe performance against the precomputed individual BLUPs within the represented population, subject to the scope clarified in Section 3.

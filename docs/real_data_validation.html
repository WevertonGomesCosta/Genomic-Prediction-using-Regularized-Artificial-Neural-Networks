1. Purpose

This module creates the common validation design used by every prediction method fitted to the real Coffea arabica population. The partitions are generated before model fitting and are reused unchanged by GBLUP and all ANN variants.

The primary validation design is a family-stratified nested cross-validation:

  • outer validation: 5 repetitions of 5 folds, producing 25 held-out evaluations;
  • outer balance: each assessment fold contains exactly 3 individuals from each of the 13 progenies;
  • inner validation: 4 folds created only within the corresponding outer analysis set;
  • inner balance: each inner assessment fold also contains exactly 3 individuals from each progeny;
  • information separation: phenotype values and prediction-model identity do not participate in fold generation.

A complementary leave-one-family-out (LOFO) design is also stored for later evaluation of between-family generalization, but it does not replace the prespecified primary nested design.

4. Repeated family-stratified outer cross-validation

Each family contains 15 individuals. Within each repetition, the 15 members of each family are shuffled reproducibly and assigned as 3 individuals to each of the five outer folds. Consequently, every outer assessment set contains 39 individuals and every outer analysis set contains 156 individuals.

outer_assignment_list <- vector("list", N_OUTER_REPEATS)
outer_splits <- list()

for (rep_id in seq_len(N_OUTER_REPEATS)) {

  set.seed(SEED_GLOBAL + rep_id)

  fold_by_row <- integer(length(ids))

  for (family_id in unique(family)) {

    family_rows <- which(family == family_id)
    shuffled_rows <- sample(family_rows, length(family_rows), replace = FALSE)

    fold_by_row[shuffled_rows] <- rep(
      seq_len(N_OUTER_FOLDS),
      each = 3L
    )
  }

  outer_assignment_list[[rep_id]] <- data.frame(
    Repetition = rep_id,
    ID = ids,
    Family = family,
    OuterFold = fold_by_row,
    stringsAsFactors = FALSE
  )

  for (outer_fold in seq_len(N_OUTER_FOLDS)) {

    split_id <- sprintf("R%02d_F%02d", rep_id, outer_fold)

    assessment_index <- which(fold_by_row == outer_fold)
    analysis_index <- which(fold_by_row != outer_fold)

    outer_splits[[split_id]] <- list(
      split_id = split_id,
      repetition = rep_id,
      outer_fold = outer_fold,
      analysis_ids = ids[analysis_index],
      assessment_ids = ids[assessment_index]
    )
  }
}

outer_assignments <- do.call(rbind, outer_assignment_list)
rownames(outer_assignments) <- NULL

5. Nested inner cross-validation

Each outer analysis set contains 12 individuals from every family. Those 12 individuals are divided into four inner folds of 3 individuals per family. Thus every inner assessment set contains 39 individuals and every inner analysis set contains 117 individuals.

The outer assessment individuals never participate in inner partition generation.

inner_assignments_list <- list()
inner_splits <- setNames(
  vector("list", length(outer_splits)),
  names(outer_splits)
)

for (split_id in names(outer_splits)) {

  outer_split <- outer_splits[[split_id]]

  rep_id <- outer_split$repetition
  outer_fold <- outer_split$outer_fold

  outer_analysis_ids <- outer_split$analysis_ids
  outer_analysis_index <- match(outer_analysis_ids, ids)
  outer_analysis_family <- family[outer_analysis_index]

  set.seed(
    SEED_GLOBAL +
      100000L +
      rep_id * 100L +
      outer_fold
  )

  inner_fold_by_row <- integer(length(outer_analysis_ids))

  for (family_id in unique(outer_analysis_family)) {

    family_rows <- which(outer_analysis_family == family_id)
    shuffled_rows <- sample(family_rows, length(family_rows), replace = FALSE)

    inner_fold_by_row[shuffled_rows] <- rep(
      seq_len(N_INNER_FOLDS),
      each = 3L
    )
  }

  inner_assignments_list[[split_id]] <- data.frame(
    SplitID = split_id,
    Repetition = rep_id,
    OuterFold = outer_fold,
    ID = outer_analysis_ids,
    Family = outer_analysis_family,
    InnerFold = inner_fold_by_row,
    stringsAsFactors = FALSE
  )

  current_inner_splits <- setNames(
    vector("list", N_INNER_FOLDS),
    paste0("I", seq_len(N_INNER_FOLDS))
  )

  for (inner_fold in seq_len(N_INNER_FOLDS)) {

    assessment_rows <- which(inner_fold_by_row == inner_fold)
    analysis_rows <- which(inner_fold_by_row != inner_fold)

    current_inner_splits[[paste0("I", inner_fold)]] <- list(
      split_id = split_id,
      inner_fold = inner_fold,
      analysis_ids = outer_analysis_ids[analysis_rows],
      assessment_ids = outer_analysis_ids[assessment_rows]
    )
  }

  inner_splits[[split_id]] <- current_inner_splits
}

10. Frozen validation contract

The primary real-data comparison is based on the same 25 family-stratified outer assessments for GBLUP and every ANN variant. ANN hyperparameter selection is restricted to the corresponding 100 inner splits; outer-assessment phenotypes remain unavailable during model development.

The complementary 13-fold LOFO design is stored independently and can later be used to quantify generalization to progenies absent from model training without changing the primary model-comparison contract.

1. Purpose

This module defines the nested cross-validation design used by every genomic-prediction method fitted to the real Coffea arabica population. The partitions are created before model fitting and are reused unchanged by GBLUP-A, GBLUP-AD, GBLUP-ADE, and all ANN variants.

The validation design has four fixed features:

  • Repeated outer cross-validation: 5 repetitions of 5 outer folds provide 25 held-out evaluations.
  • Nested inner cross-validation: each outer analysis set is divided into 4 inner folds for ANN model selection.
  • Common partitions: the same outer and inner assignments are reused for Cer, BM, LP, GBLUP-A, GBLUP-AD, GBLUP-ADE, and all ANN configurations.
  • Information separation: BLUP values, genomic marker values, and model identity do not participate in fold generation.

Throughout this module, analysis set denotes individuals available for model development at the current validation level, whereas assessment set denotes individuals held out for evaluation at that level.

4. Repeated outer cross-validation

In each repetition, the 195 individuals are randomly shuffled and divided into five folds of equal size. Because 195 is exactly divisible by five, every outer assessment fold contains 39 individuals and the remaining 156 individuals form the corresponding outer analysis set.

4.1 Outer fold assignments

outer_assignment_list <- vector(
  "list",
  N_OUTER_REPEATS
)

outer_splits <- list()

for (rep_id in seq_len(N_OUTER_REPEATS)) {

  set.seed(
    SEED_GLOBAL + rep_id
  )

  shuffled_ids <- sample(
    ids,
    size = length(ids),
    replace = FALSE
  )

  assigned_folds <- rep(
    seq_len(N_OUTER_FOLDS),
    each = length(ids) / N_OUTER_FOLDS
  )

  assignment <- data.frame(
    Repetition = rep_id,
    ID = shuffled_ids,
    OuterFold = assigned_folds,
    stringsAsFactors = FALSE
  )

  assignment <- assignment[
    order(assignment$ID),
    ,
    drop = FALSE
  ]

  rownames(
    assignment
  ) <- NULL

  assignment$SplitID <- sprintf(
    "R%02d_F%02d",
    assignment$Repetition,
    assignment$OuterFold
  )

  outer_assignment_list[[rep_id]] <- assignment

  for (outer_fold in seq_len(N_OUTER_FOLDS)) {

    split_id <- sprintf(
      "R%02d_F%02d",
      rep_id,
      outer_fold
    )

    assessment_ids <- assignment$ID[
      assignment$OuterFold == outer_fold
    ]

    analysis_ids <- ids[
      !ids %in% assessment_ids
    ]

    outer_splits[[split_id]] <- list(
      split_id = split_id,
      repetition = rep_id,
      outer_fold = outer_fold,
      analysis_ids = analysis_ids,
      assessment_ids = assessment_ids
    )
  }
}

5. Nested inner cross-validation

Each outer analysis set contains 156 individuals. Within each outer split, these individuals are randomly shuffled and divided into four equal inner folds.

Each inner assessment set therefore contains 39 individuals, while the remaining 117 individuals form the corresponding inner analysis set. The outer assessment individuals do not participate in inner partition generation.

    order(inner_assignment$ID),

9. Validation input for genomic prediction

The primary model comparison uses the same 25 outer assessment sets for GBLUP-A, GBLUP-AD, GBLUP-ADE, and every ANN configuration. ANN model selection is restricted to the 100 inner splits nested within the corresponding outer analysis sets.

No phenotypic or genomic values are used to create the validation partitions.

1. Objective

This analysis freezes the validation design used by all genomic prediction models fitted to the simulated dataset.

The design is created before model fitting and is independent of phenotype, true genetic value, scenario, and model. Consequently, GBLUP-ADE and all ANN variants are evaluated on exactly the same outer assessment individuals.

The canonical design uses:

  • 5 outer folds;
  • 5 outer repetitions;
  • 4 inner folds within each outer analysis set;
  • deterministic seeds derived from the project-wide seed;
  • the same outer and inner partitions for all six simulation scenarios.

The outer assessment sets are reserved exclusively for final model evaluation. The inner folds are reserved for ANN hyperparameter tuning. True simulated genetic values are never used to generate partitions or tune models.

1.1 How to read this module

The validation scheme separates model development from final predictive evaluation. An analysis set contains the individuals available for fitting or tuning, whereas the corresponding assessment set remains held out for evaluation at that level of cross-validation. Outer assessment individuals are therefore never used to choose ANN hyperparameters or training duration.

The sections below show the individual universe, partition sizes, overlap, and coverage directly. The validation structure can therefore be inspected from the displayed objects rather than inferred from boolean checks.

4. Outer repeated cross-validation

4.1 Balanced fold assignment

The helper below randomizes the supplied IDs with sample() and then cycles through the fold labels with rep(). Sorting by ID at the end changes only the display/order of the assignment table, not the randomized fold membership.

balanced_fold_assignment <- function(
  ids,
  k,
  seed
) {
  set.seed(seed)

  shuffled_ids <- sample(
    ids,
    size = length(ids),
    replace = FALSE
  )

  assigned_folds <- rep(
    seq_len(k),
    length.out = length(ids)
  )

  out <- data.frame(
    ID = shuffled_ids,
    Fold = assigned_folds,
    stringsAsFactors = FALSE
  )

  out <- out[
    order(out$ID),
    ,
    drop = FALSE
  ]

  rownames(out) <- NULL
  out
}

For 1,000 individuals and five outer folds, this produces 200 assessment individuals per fold. Applied to an 800-individual outer-analysis set with four inner folds, it produces 200 inner-assessment individuals per fold.

5. Nested inner cross-validation

5.1 Inner partition generation

Each outer analysis set is partitioned again for ANN hyperparameter selection. Within a given outer split, one inner fold acts as the assessment subset and the remaining inner individuals form the analysis subset. The outer assessment set never participates in this operation.

inner_assignments_list <- vector("list", length(outer_splits))
names(inner_assignments_list) <- names(outer_splits)
inner_splits <- setNames(
  vector("list", length(outer_splits)),
  names(outer_splits)
)

# Generate four inner folds separately inside each outer analysis set.
for (split_id in names(outer_splits)) {
  outer_split <- outer_splits[[split_id]]
  split_tokens <- strsplit(sub("^R", "", split_id), "_F")[[1]]
  rep_id <- as.integer(split_tokens[1])
  outer_fold <- as.integer(split_tokens[2])
  inner_seed <- SEED_GLOBAL + 100000L + rep_id * 100L + outer_fold

  assignment <- balanced_fold_assignment(
    ids = outer_split$analysis_ids,
    k = N_INNER_FOLDS,
    seed = inner_seed
  )

  inner_assignments_list[[split_id]] <- data.frame(
    SplitID = split_id,
    Repetition = rep_id,
    OuterFold = outer_fold,
    ID = assignment$ID,
    InnerFold = assignment$Fold,
    stringsAsFactors = FALSE
  )

  current_inner_splits <- setNames(
    vector("list", N_INNER_FOLDS),
    paste0("I", seq_len(N_INNER_FOLDS))
  )

  # Convert each inner fold into explicit analysis and assessment ID sets.
  for (inner_fold in seq_len(N_INNER_FOLDS)) {
    inner_assessment_ids <- assignment$ID[assignment$Fold == inner_fold]
    inner_analysis_ids <- setdiff(
      outer_split$analysis_ids,
      inner_assessment_ids
    )
    current_inner_splits[[paste0("I", inner_fold)]] <- list(
      split_id = split_id,
      inner_fold = inner_fold,
      analysis_ids = sort(inner_analysis_ids),
      assessment_ids = sort(inner_assessment_ids)
    )
  }
  inner_splits[[split_id]] <- current_inner_splits
}

inner_assignments <- do.call(rbind, inner_assignments_list)

6.2 Information excluded

Scenario labels, phenotype values, true simulated genetic values, and model identity do not participate in fold generation. The same frozen partitions can therefore be reused fairly by GBLUP-ADE and every ANN variant.

In particular, true genetic values are retained in the canonical data object only for held-out predictive evaluation. They never enter partitioning, ANN hyperparameter tuning, or training-duration selection.

7. Frozen validation design

7.1 Validation contract

The frozen design establishes three levels of separation:

  • Outer evaluation: five repetitions of five outer folds produce 25 outer splits, each with 800 analysis and 200 untouched assessment individuals.
  • Inner ANN tuning: each 800-individual outer-analysis set is divided into four inner folds, each with 600 analysis and 200 inner-assessment individuals. ANN architecture, learning rate, L1, and L2 are selected only within these inner splits; early validation is drawn only from the current inner-analysis subset.
  • Final evaluation: the same outer splits are used for C1-C6 and every prediction method. Primary true-G and secondary phenotype metrics are calculated only after the final model predicts the untouched outer-assessment individuals.

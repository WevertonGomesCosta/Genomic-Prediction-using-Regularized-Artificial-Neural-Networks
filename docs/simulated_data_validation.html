Purpose

This analysis freezes the validation design used by all genomic prediction models fitted to the simulated dataset.

The design is created before model fitting and is independent of phenotype, true genetic value, scenario, and model. Consequently, GBLUP-ADE and all ANN variants are evaluated on exactly the same outer assessment individuals.

The canonical design uses:

  • 5 outer folds;
  • 5 outer repetitions;
  • 4 inner folds within each outer analysis set;
  • deterministic seeds derived from the project-wide seed;
  • the same outer and inner partitions for all six simulation scenarios.

The outer assessment sets are reserved exclusively for final model evaluation. The inner folds are reserved for ANN hyperparameter tuning. True simulated genetic values are never used to generate partitions or tune models.

How to read the validation design

The validation scheme separates model development from final predictive evaluation. An analysis set contains the individuals available for fitting or tuning, whereas the corresponding assessment set remains held out for evaluation at that level of cross-validation. Outer assessment individuals are therefore never used to choose ANN hyperparameters or training duration.

The sections below show the individual universe, partition sizes, overlap, and coverage directly. The validation structure can therefore be inspected from the displayed objects rather than inferred from boolean checks.

Balanced fold assignment

The helper below randomizes the supplied IDs with sample() and then cycles through the fold labels with rep(). Sorting by ID at the end changes only the display/order of the assignment table, not the randomized fold membership.

balanced_fold_assignment <- function(
  ids,
  k,
  seed
) {
  set.seed(seed)

  shuffled_ids <- sample(
    ids,
    size = length(ids),
    replace = FALSE
  )

  assigned_folds <- rep(
    seq_len(k),
    length.out = length(ids)
  )

  out <- data.frame(
    ID = shuffled_ids,
    Fold = assigned_folds,
    stringsAsFactors = FALSE
  )

  out <- out[
    order(out$ID),
    ,
    drop = FALSE
  ]

  rownames(out) <- NULL
  out
}

For 1,000 individuals and five outer folds, this produces 200 assessment individuals per fold. Applied to an 800-individual outer-analysis set with four inner folds, it produces 200 inner-assessment individuals per fold.

Outer repeated cross-validation

For each repetition, sample() randomly permutes the 1,000 canonical individual IDs using a deterministic seed. rep() then assigns the shuffled IDs across five fold labels as evenly as possible. Because 1,000 is exactly divisible by five, every outer assessment fold contains 200 individuals and the remaining 800 form its outer analysis set.

The same procedure is repeated five times with different deterministic seeds, producing 25 outer train–test comparisons while preserving exact reproducibility.

outer_assignments <- do.call(
  rbind,
  lapply(seq_len(N_OUTER_REPEATS), function(rep_id) {
    assignment <- balanced_fold_assignment(
      ids = ids,
      k = N_OUTER_FOLDS,
      seed = SEED_GLOBAL + rep_id
    )
    data.frame(
      Repetition = rep_id,
      ID = assignment$ID,
      OuterFold = assignment$Fold,
      stringsAsFactors = FALSE
    )
  })
)

Explicit outer split objects

The assignment table is then converted into explicit analysis and assessment ID sets for each outer split. For a given split, setdiff() removes the 200 assessment IDs from the 1,000-individual universe, leaving the corresponding 800-individual analysis set. This representation is the object consumed by the modeling modules.

Each explicit split object therefore stores the 800 IDs available to model development and the 200 IDs reserved for final assessment. setdiff() makes the two sets disjoint while preserving complete coverage of the 1,000 individuals.

Nested inner folds

Each outer analysis set is partitioned again for ANN hyperparameter selection. Within a given outer split, one inner fold acts as the assessment subset and the remaining inner individuals form the analysis subset. The operation setdiff() constructs the analysis IDs by removing the current assessment IDs, which makes the two sets disjoint by construction.

With 800 individuals in each outer analysis set and four inner folds, every inner assessment set contains 200 individuals and every inner analysis set contains 600.

inner_assignments_list <- vector("list", length(outer_splits))
names(inner_assignments_list) <- names(outer_splits)
inner_splits <- setNames(
  vector("list", length(outer_splits)),
  names(outer_splits)
)

for (split_id in names(outer_splits)) {
  outer_split <- outer_splits[[split_id]]
  split_tokens <- strsplit(sub("^R", "", split_id), "_F")[[1]]
  rep_id <- as.integer(split_tokens[1])
  outer_fold <- as.integer(split_tokens[2])

  assignment <- balanced_fold_assignment(
    ids = outer_split$analysis_ids,

    SplitID = split_id,
    Repetition = rep_id,
    OuterFold = outer_fold,

    InnerFold = assignment$Fold,
    stringsAsFactors = FALSE
  )

    vector("list", N_INNER_FOLDS),
    paste0("I", seq_len(N_INNER_FOLDS))

    inner_assessment_ids <- assignment$ID[assignment$Fold == inner_fold]

      outer_split$analysis_ids,
      inner_assessment_ids

      split_id = split_id,
      inner_fold = inner_fold,
      analysis_ids = sort(inner_analysis_ids),
      assessment_ids = sort(inner_assessment_ids)
    )
  }
  inner_splits[[split_id]] <- current_inner_splits
}

Validation contract

Outer evaluation

  • Five repetitions of five outer folds produce 25 outer splits.
  • Each split contains 800 analysis and 200 assessment individuals.
  • Outer assessment data remain untouched until the final prediction step.

Inner ANN tuning

  • Each 800-individual outer-analysis set is divided into four inner folds.
  • Each inner split contains 600 analysis and 200 inner-assessment individuals.
  • ANN architecture, learning rate, L1, and L2 are selected only within these inner splits; early validation is drawn only from the current inner-analysis subset.

Final evaluation

  • The same outer splits are used for C1-C6 and every prediction method.
  • True genetic values never enter partitioning, tuning, or epoch selection.
  • Primary true-G and secondary phenotype metrics are calculated only after the final model has predicted the untouched outer-assessment individuals.

Purpose

This module is the canonical ANN workflow for the simulated genomic-data branch. ANN hyperparameter tuning and final outer-CV fitting are internal stages of one modeling method, parallel to GBLUP in the public pipeline.

The four variants are ANN_0, ANN_L1, ANN_L2, and ANN_L1_L2 (displayed as ANN-L1+L2). They use the same multilayer perceptron and differ only in L1/L2 weight penalties.

Tuning contract

Only four quantities are treated as hyperparameters:

  1. hidden-layer architecture;
  2. Adam learning rate;
  3. L1 penalty coefficient;
  4. L2 penalty coefficient.

The following are fixed optimization controls, not tuned quantities:

  • activation: ReLU;
  • optimizer: Adam;
  • dropout: 0;
  • maximum epochs available to an early-stopped fit: 2000;
  • patience: 25;
  • minimum validation improvement: \(10^{-6}\);
  • early-validation fraction: 0.15.

Optimization concepts used in this workflow

These controls describe how each candidate network is optimized; they are distinct from the scientific comparison among ANN variants.

  • Adam is the gradient-based optimizer used to update the network weights. It adapts the magnitude of parameter updates from the recent history of the gradients. In this workflow Adam is fixed as the optimizer; it is not compared with alternative optimization algorithms.
  • The learning rate controls the size of the optimization steps taken by Adam. It is a tuned quantity and is selected together with network architecture using ANN_0 within each outer task.
  • An epoch is one complete pass through the fitting observations used in a particular network fit. The number of epochs completed is therefore an optimization quantity, not a new cross-validation replicate.
  • Early stopping monitors loss on the separate early-validation subset during optimization and stops training when additional epochs no longer produce sufficient improvement. The frozen inner-assessment and outer- assessment observations are not used for this stopping decision.
  • Patience = 25 means that optimization stops after 25 consecutive epochs without a qualifying improvement in early-validation loss.
  • Minimum improvement (min_delta) = \(10^{-6}\) defines the decrease in early-validation loss required to count as an improvement and reset the patience counter. Changes smaller than this threshold do not reset patience.

Thus, early stopping determines how long an individual optimization run is allowed to continue, whereas nested cross-validation determines which prespecified architecture, learning rate, and penalty configuration is selected.

The 2000-epoch value is a convergence ceiling, not a fixed final training length. Epoch diagnostics are excluded from hyperparameter ranking. After hyperparameters are selected, a separate early-stopping fit uses only the outer-analysis sample to select Best_epoch; the final network is then reinitialized and refit on all 800 outer-analysis individuals for exactly Best_epoch.

Architecture range

The canonical architecture catalog defines a bounded small-to-moderate feed-forward network search space. The candidate hidden-layer structures are 2, 4, 8, 16, 32, 8-4, 16-8, 32-16, and 64-32.

The 64-32 architecture is the prespecified upper bound of the canonical search space. Consequently, all ANN results and the subsequent comparison with GBLUP-ADE are interpreted within the prespecified canonical model/architecture search space, rather than as a comparison against every possible neural-network architecture.

Canonical inputs

This module uses the audited common preprocessing object and the frozen nested validation design established in the preceding modules. These fixed inputs keep model tuning and outer-CV evaluation aligned across all four ANN variants. Their dimensions, genotype coding, scenario names, and frozen split counts are verified internally before any ANN tuning summary is interpreted.

Within-fold preprocessing

For every inner fit, marker means and standard deviations are estimated only from the fitting subset. Those same parameters are then applied to the corresponding early-validation and inner-assessment individuals. Phenotypes are standardized from the fitting subset in the same way, and predictions are returned to the original phenotype scale before calculating performance metrics. Markers with effectively zero fitting-set variance receive unit scale to avoid numerical division by zero.

This ordering prevents validation or assessment observations from influencing the preprocessing parameters used to fit the network.

Shared ANN implementation

For standardized marker vector \(\mathbf{x}\), hidden layers apply affine transformations followed by ReLU activation,

\[ \mathbf{h}^{(0)}=\mathbf{x}, \qquad \mathbf{h}^{(\ell)}=\operatorname{ReLU}(\mathbf{W}_{\ell}\mathbf{h}^{(\ell-1)}+\mathbf{b}_{\ell}), \]

with a linear output layer

\[ \hat{y}=\mathbf{w}_{o}^{\mathsf{T}}\mathbf{h}^{(L)}+b_o. \]

Training minimizes

\[ \mathcal{L}= \operatorname{MSE}(y,\hat{y})+ \lambda_1\sum_j |w_j|+ \frac{\lambda_2}{2}\sum_j w_j^2. \]

In this objective, \(y\) is the observed phenotype on the standardized scale defined from the current fitting subset, and \(\hat{y}\) is the corresponding network prediction on that same scale during optimization. The terms \(w_j\) denote the penalized network weights, while \(\lambda_1\) and \(\lambda_2\) control the strengths of the L1 and L2 penalties, respectively. Bias parameters are excluded from both penalty sums.

Standardization is used only to fit the network on a common numerical scale. Before inner-assessment or outer-assessment performance is calculated, predictions are transformed back with the fitting-set phenotype mean and standard deviation, so the reported prediction errors are expressed on the original phenotype scale.

ANN_0 sets both penalty coefficients to zero, ANN_L1 uses a selected positive \(\lambda_1\) with \(\lambda_2=0\), ANN_L2 uses a selected positive \(\lambda_2\) with \(\lambda_1=0\), and ANN_L1_L2 uses selected positive values of both coefficients. Penalties are applied to network weights but not biases. Adam uses weight_decay = 0, so the L2 contribution enters only through the explicit weight_penalty() term shown below.

TorchGenomicMLP <- torch::nn_module(
  "TorchGenomicMLP_CanonicalTuning",

  initialize = function(
    input_dim,
    hidden_units
  ) {
    self$linears <-
      torch::nn_module_list()

    previous <-
      as.integer(input_dim)

    for (h in hidden_units) {
      self$linears$append(
        torch::nn_linear(
          previous,
          as.integer(h)
        )
      )
      previous <- as.integer(h)
    }

    self$output <-
      torch::nn_linear(
        previous,
        1L
      )
  },

  forward = function(x) {
    if (length(self$linears) > 0L) {
      for (
        i in seq_len(
          length(self$linears)
        )
      ) {
        x <- torch::nnf_relu(
          self$linears[[i]](x)
        )
      }
    }

    self$output(x)
  }
)

weight_penalty <- function(
  model,
  l1,
  l2
) {
  weights <- lapply(
    seq_len(
      length(model$linears)
    ),
    function(i) {
      model$linears[[i]]$weight
    }
  )

  weights[[length(weights) + 1L]] <-
    model$output$weight

  zero <- weights[[1]]$sum() * 0
  penalty_l1 <- zero
  penalty_l2 <- zero

  for (w in weights) {
    penalty_l1 <-
      penalty_l1 +
      w$abs()$sum()

    penalty_l2 <-
      penalty_l2 +
      w$pow(2)$sum()
  }

  l1 * penalty_l1 +
    (l2 / 2) * penalty_l2
}

clone_state <- function(model) {
  state <- model$state_dict()

  copy <- lapply(
    state,
    function(x) {
      x$detach()$clone()
    }
  )

  names(copy) <- names(state)

  copy
}

Inner-CV training

The inner analysis set is divided deterministically into:

  • a fitting subset;
  • an early-validation subset.

The frozen inner assessment set remains untouched until prediction of that candidate. Preprocessing is estimated from the fitting subset only.

Early stopping is an optimization mechanism. Its epoch diagnostics are saved but excluded from the tuning rule.

prepare_bundle <- function(
  fit_ids,
  validation_ids,
  assessment_ids,
  scenario_index
) {
  fit_index <- match(
    fit_ids,
    ids
  )
  validation_index <- match(
    validation_ids,
    ids
  )
  assessment_index <- match(
    assessment_ids,
    ids
  )

  if (
    anyNA(
      c(
        fit_index,
        validation_index,
        assessment_index
      )
    )
  ) {
    stop(
      "ANN ID alignment failed."
    )
  }

  x_scaler <- fit_x_scaler(
    geno[
      fit_index,
      ,
      drop = FALSE
    ]
  )

  y_scaler <- fit_y_scaler(
    phenotype[
      fit_index,
      scenario_index
    ]
  )

  list(
    x_fit = scale_x(
      geno[
        fit_index,
        ,
        drop = FALSE
      ],
      x_scaler
    ),
    x_validation = scale_x(
      geno[
        validation_index,
        ,
        drop = FALSE
      ],
      x_scaler
    ),
    x_assessment = scale_x(
      geno[
        assessment_index,
        ,
        drop = FALSE
      ],
      x_scaler
    ),
    y_fit = scale_y(
      phenotype[
        fit_index,
        scenario_index
      ],
      y_scaler
    ),
    y_validation = scale_y(
      phenotype[
        validation_index,
        scenario_index
      ],
      y_scaler
    ),
    y_assessment = phenotype[
      assessment_index,
      scenario_index
    ],
    y_scaler = y_scaler,
    zero_variance_markers =
      sum(x_scaler$zero)
  )
}

train_inner_candidate <- function(
  bundle,
  architecture,
  learning_rate,
  l1,
  l2,
  seed
) {
  set_ann_seed(seed)

  x_fit <- torch::torch_tensor(
    bundle$x_fit,
    dtype = torch::torch_float()
  )$to(device = ANN_DEVICE)

  y_fit <- torch::torch_tensor(
    matrix(
      bundle$y_fit,
      ncol = 1
    ),
    dtype = torch::torch_float()
  )$to(device = ANN_DEVICE)

  x_validation <- torch::torch_tensor(
    bundle$x_validation,
    dtype = torch::torch_float()
  )$to(device = ANN_DEVICE)

  y_validation <- torch::torch_tensor(
    matrix(
      bundle$y_validation,
      ncol = 1
    ),
    dtype = torch::torch_float()
  )$to(device = ANN_DEVICE)

  x_assessment <- torch::torch_tensor(
    bundle$x_assessment,
    dtype = torch::torch_float()
  )$to(device = ANN_DEVICE)

  model <- TorchGenomicMLP(
    ncol(bundle$x_fit),
    ARCHITECTURES[[architecture]]
  )$to(device = ANN_DEVICE)

  optimizer <- torch::optim_adam(
    params = model$parameters,
    lr = learning_rate,
    weight_decay = 0
  )

  best_validation_loss <- Inf
  checkpoint_epoch <- NA_integer_
  checkpoint_state <- NULL
  stale <- 0L
  last_epoch <- 0L
  stopped_by_patience <- FALSE

  sync_device()
  fit_start <-
    proc.time()[["elapsed"]]

  for (
    epoch in seq_len(MAX_EPOCHS)
  ) {
    last_epoch <- epoch

    model$train()
    optimizer$zero_grad()

    prediction <-
      model(x_fit)

    loss <-
      torch::nnf_mse_loss(
        prediction,
        y_fit
      ) +
      weight_penalty(
        model,
        l1,
        l2
      )

    loss$backward()
    optimizer$step()

    model$eval()

    validation_loss <-
      torch::with_no_grad({
        torch::nnf_mse_loss(
          model(x_validation),
          y_validation
        )
      })

    validation_value <-
      as.numeric(
        validation_loss$to(
          device =
            torch::torch_device("cpu")
        )
      )

    if (
      is.finite(validation_value) &&
      validation_value <
        best_validation_loss -
        MIN_DELTA
    ) {
      best_validation_loss <-
        validation_value

      checkpoint_epoch <-
        epoch

      checkpoint_state <-
        clone_state(model)

      stale <- 0L
    } else {
      stale <- stale + 1L
    }

    if (stale >= PATIENCE) {
      stopped_by_patience <- TRUE
      break
    }
  }

  sync_device()
  fit_seconds <-
    proc.time()[["elapsed"]] -
    fit_start

  if (
    is.null(checkpoint_state) ||
    is.na(checkpoint_epoch)
  ) {
    stop(
      "No finite early-validation checkpoint."
    )
  }

  model$load_state_dict(
    checkpoint_state
  )
  model$eval()

  sync_device()
  prediction_start <-
    proc.time()[["elapsed"]]

  prediction_scaled <-
    torch::with_no_grad({
      as.numeric(
        model(x_assessment)$to(
          device =
            torch::torch_device("cpu")
        )
      )
    })

  sync_device()
  prediction_seconds <-
    proc.time()[["elapsed"]] -
    prediction_start

  list(
    prediction = unscale_y(
      prediction_scaled,
      bundle$y_scaler
    ),
    early_stop_epoch =
      as.integer(checkpoint_epoch),
    last_epoch =
      as.integer(last_epoch),
    stopped_by_patience =
      stopped_by_patience,
    hit_epoch_ceiling =
      last_epoch >= MAX_EPOCHS &&
      !stopped_by_patience,
    fit_seconds = fit_seconds,
    prediction_seconds =
      prediction_seconds,
    zero_variance_markers =
      bundle$zero_variance_markers
  )
}

Candidate evaluation and selection

Candidate ranking is deterministic and does not include epoch information.

The ranking hierarchy is:

  1. lower mean inner-assessment RMSE;
  2. higher mean inner-assessment correlation;
  3. fewer network parameters;
  4. smaller total penalty coefficient;
  5. smaller learning rate;
  6. candidate ID.
evaluate_candidate <- function(
  bundles,
  model_name,
  architecture,
  learning_rate,
  l1,
  l2,
  seed_base,
  candidate_id
) {
  rows <- vector(
    "list",
    4L
  )

  for (k in 1:4) {
    fitted <- tryCatch(
      train_inner_candidate(
        bundles[[k]],
        architecture,
        learning_rate,
        l1,
        l2,
        seed_base + k
      ),
      error = function(e) e
    )

    if (
      inherits(
        fitted,
        "error"
      )
    ) {
      rows[[k]] <- data.frame(
        Model = model_name,
        CandidateID = candidate_id,
        Architecture = architecture,
        Learning_rate = learning_rate,
        L1 = l1,
        L2 = l2,
        InnerFold = k,
        RMSE = NA_real_,
        Correlation = NA_real_,
        MAE = NA_real_,
        EarlyStop_epoch = NA_integer_,
        Last_epoch = NA_integer_,
        Stopped_by_patience = NA,
        Hit_epoch_ceiling = NA,
        Fit_seconds = NA_real_,
        Prediction_seconds = NA_real_,
        Status = "error",
        Error = conditionMessage(fitted),
        stringsAsFactors = FALSE
      )
    } else {
      rows[[k]] <- data.frame(
        Model = model_name,
        CandidateID = candidate_id,
        Architecture = architecture,
        Learning_rate = learning_rate,
        L1 = l1,
        L2 = l2,
        InnerFold = k,
        RMSE = safe_rmse(
          fitted$prediction,
          bundles[[k]]$y_assessment
        ),
        Correlation = safe_cor(
          fitted$prediction,
          bundles[[k]]$y_assessment
        ),
        MAE = safe_mae(
          fitted$prediction,
          bundles[[k]]$y_assessment
        ),
        EarlyStop_epoch =
          fitted$early_stop_epoch,
        Last_epoch =
          fitted$last_epoch,
        Stopped_by_patience =
          fitted$stopped_by_patience,
        Hit_epoch_ceiling =
          fitted$hit_epoch_ceiling,
        Fit_seconds =
          fitted$fit_seconds,
        Prediction_seconds =
          fitted$prediction_seconds,
        Status = "ok",
        Error = NA_character_,
        stringsAsFactors = FALSE
      )
    }
  }

  folds <- do.call(
    rbind,
    rows
  )

  ok <- folds$Status == "ok"

  summary <- data.frame(
    Model = model_name,
    CandidateID = candidate_id,
    Architecture = architecture,
    Learning_rate = learning_rate,
    L1 = l1,
    L2 = l2,
    Inner_folds_ok = sum(ok),
    Mean_RMSE = if (all(ok)) {
      mean(folds$RMSE)
    } else {
      NA_real_
    },
    Mean_Correlation = if (all(ok)) {
      mean(folds$Correlation)
    } else {
      NA_real_
    },
    Mean_MAE = if (all(ok)) {
      mean(folds$MAE)
    } else {
      NA_real_
    },
    Median_EarlyStop_epoch = if (all(ok)) {
      median(folds$EarlyStop_epoch)
    } else {
      NA_real_
    },
    Max_Last_epoch = if (all(ok)) {
      max(folds$Last_epoch)
    } else {
      NA_real_
    },
    N_epoch_ceiling = if (all(ok)) {
      sum(folds$Hit_epoch_ceiling)
    } else {
      NA_integer_
    },
    Status = if (all(ok)) {
      "ok"
    } else {
      "incomplete"
    },
    stringsAsFactors = FALSE
  )

  list(
    summary = summary,
    folds = folds
  )
}

choose_candidate <- function(x) {
  eligible <- x[
    x$Status == "ok" &
      is.finite(x$Mean_RMSE),
    ,
    drop = FALSE
  ]

  if (!nrow(eligible)) {
    stop(
      "No complete ANN candidate is available."
    )
  }

  eligible$Parameters <- vapply(
    eligible$Architecture,
    function(architecture) {
      parameter_count(
        ncol(geno),
        ARCHITECTURES[[architecture]]
      )
    },
    numeric(1)
  )

  eligible$Penalty <-
    eligible$L1 +
    eligible$L2

  eligible <- eligible[
    order(
      eligible$Mean_RMSE,
      -eligible$Mean_Correlation,
      eligible$Parameters,
      eligible$Penalty,
      eligible$Learning_rate,
      eligible$CandidateID
    ),
    ,
    drop = FALSE
  ]

  # Epoch diagnostics are intentionally absent from the ranking above.
  eligible[
    1,
    ,
    drop = FALSE
  ]
}

From tuning to final fitting

Nested tuning produces one selected architecture, learning rate, and applicable penalty coefficient(s) for each Scenario × outer split × ANN variant. The final stage consumes those selections directly under the same frozen validation design; hyperparameter selection is not repeated.

Final ANN fitting

The tuning stage uses a 2000-epoch convergence ceiling. Final epoch selection uses a separate 3000-epoch safety ceiling so that patience-based stopping can operate within the outer-analysis sample without imposing a fixed training length. The 3000-epoch value is only an upper bound: each final network is reinitialized and refit on all 800 outer-analysis individuals for exactly its selected Best_epoch.

The final stage consumes the selected hyperparameters from nested tuning; it does not repeat model selection.

For each Scenario × outer split × ANN variant, Best_epoch is selected with early stopping using only the 800 outer-analysis individuals. The network is then reinitialized, refit on all 800 for exactly Best_epoch, and only then applied to the untouched 200 outer-assessment individuals.

Saved final-result integrity

Before final predictive summaries are shown, the 600 model-task rows, 120,000 held-out predictions, 600 epoch-selection rows, finite predictions, selected epoch range, and leakage-prevention flags are checked internally against the canonical final-fitting contract.

Across the 600 final epoch-selection fits, 600 stopped by patience and 0 reached the 3000-epoch ceiling without a patience stop. Thus, the final ceiling acts as a safety bound rather than a fixed training length; each network is subsequently refit for its selected Best_epoch.

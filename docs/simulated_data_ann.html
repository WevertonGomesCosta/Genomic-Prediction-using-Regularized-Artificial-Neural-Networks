Purpose

This module is the canonical ANN workflow for the simulated genomic-data branch. ANN hyperparameter tuning and final outer-CV fitting are internal stages of one modeling method, parallel to GBLUP in the public pipeline.

The four variants are ANN_0, ANN_L1, ANN_L2, and ANN_L1_L2 (displayed as ANN-L1+L2). They use the same multilayer perceptron and differ only in L1/L2 weight penalties.

Tuning contract

The four ANN variants use the same multilayer perceptron. They differ only in the L1 and L2 coefficients applied to the network weights.

Tuned hyperparameters

Hyperparameter Role
Architecture number of hidden units/layers
Learning rate Adam step size
L1 coefficient strength of absolute-weight penalty
L2 coefficient strength of squared-weight penalty

Architecture and learning rate are selected once per outer task with ANN_0 and then shared by all four ANN variants. The regularized variants subsequently select only their penalty coefficient(s).

Fixed optimization controls

Control Canonical value
Activation ReLU
Optimizer Adam
Dropout 0
Maximum tuning epochs 2000
Patience 25
Minimum improvement (min_delta) \(10^{-6}\)
Early-validation fraction 0.15

These values control how a candidate is optimized; they are not additional hyperparameters in the scientific comparison.

Early stopping

An epoch is one complete pass through the current fitting observations. Early stopping monitors loss on a separate early-validation subset drawn only from the current analysis sample. Training stops after 25 consecutive epochs without an improvement of at least \(10^{-6}\).

The 2000-epoch value is therefore a convergence ceiling, not a fixed training length. Epoch diagnostics are excluded from candidate ranking.

Architecture range

The canonical architecture catalog defines a bounded small-to-moderate feed-forward network search space. The candidate hidden-layer structures are 2, 4, 8, 16, 32, 8-4, 16-8, 32-16, and 64-32.

The 64-32 architecture is the prespecified upper bound of the canonical search space. Consequently, all ANN results and the subsequent comparison with GBLUP-ADE are interpreted within the prespecified canonical model/architecture search space, rather than as a comparison against every possible neural-network architecture.

Canonical inputs

This module uses the audited common preprocessing object and the frozen nested validation design established in the preceding modules. These fixed inputs keep model tuning and outer-CV evaluation aligned across all four ANN variants. Their dimensions, genotype coding, scenario names, and frozen split counts are verified internally before any ANN tuning summary is interpreted.

Within-fold preprocessing

For every inner fit, marker means and standard deviations are estimated only from the fitting subset. Those same parameters are then applied to the corresponding early-validation and inner-assessment individuals. Phenotypes are standardized from the fitting subset in the same way, and predictions are returned to the original phenotype scale before calculating performance metrics. Markers with effectively zero fitting-set variance receive unit scale to avoid numerical division by zero.

This ordering prevents validation or assessment observations from influencing the preprocessing parameters used to fit the network.

safe_cor <- function(p, o) {
  z <- is.finite(p) & is.finite(o)

  if (
    sum(z) < 3L ||
    sd(p[z]) == 0 ||
    sd(o[z]) == 0
  ) {
    return(NA_real_)
  }

  cor(p[z], o[z])
}

safe_rmse <- function(p, o) {
  z <- is.finite(p) & is.finite(o)

  if (!any(z)) {
    return(NA_real_)
  }

  sqrt(
    mean(
      (p[z] - o[z])^2
    )
  )
}

safe_mae <- function(p, o) {
  z <- is.finite(p) & is.finite(o)

  if (!any(z)) {
    return(NA_real_)
  }

  mean(
    abs(
      p[z] - o[z]
    )
  )
}

make_validation_split <- function(
  x,
  frac,
  seed
) {
  set.seed(seed)

  n_validation <- max(
    1L,
    as.integer(
      round(
        length(x) * frac
      )
    )
  )

  validation <- sort(
    sample(
      x,
      n_validation
    )
  )

  list(
    train = sort(
      setdiff(
        x,
        validation
      )
    ),
    validation = validation
  )
}

fit_x_scaler <- function(x) {
  center <- colMeans(x)
  scale <- apply(
    x,
    2,
    sd
  )

  zero <- !is.finite(scale) |
    scale < 1e-8

  scale[zero] <- 1

  list(
    center = center,
    scale = scale,
    zero = zero
  )
}

scale_x <- function(x, scaler) {
  sweep(
    sweep(
      x,
      2,
      scaler$center,
      "-"
    ),
    2,
    scaler$scale,
    "/"
  )
}

fit_y_scaler <- function(y) {
  scale <- sd(y)

  if (
    !is.finite(scale) ||
    scale < 1e-8
  ) {
    scale <- 1
  }

  list(
    center = mean(y),
    scale = scale
  )
}

scale_y <- function(y, scaler) {
  (
    y - scaler$center
  ) / scaler$scale
}

unscale_y <- function(y, scaler) {
  y * scaler$scale +
    scaler$center
}

Shared ANN implementation

Network objects

For a standardized marker vector \(\mathbf{x}\), each hidden layer applies a linear transformation followed by ReLU activation:

\[ \mathbf{h}^{(\ell)} = \operatorname{ReLU} (\mathbf{W}_{\ell}\mathbf{h}^{(\ell-1)}+\mathbf{b}_{\ell}). \]

Symbol Meaning
\(\mathbf{x}\) standardized marker vector
\(\mathbf{W}\) layer weights
\(\mathbf{b}\) layer biases
\(\mathbf{h}\) hidden-layer activations
\(\hat{y}\) network prediction

The output layer is linear because the response is continuous.

Loss and regularization

Training minimizes

\[ \mathcal{L}= \operatorname{MSE}(y,\hat{y})+ \lambda_1\sum_j |w_j|+ \frac{\lambda_2}{2}\sum_j w_j^2. \]

ANN_0 uses \(\lambda_1=\lambda_2=0\), ANN_L1 uses only L1, ANN_L2 uses only L2, and ANN_L1_L2 uses both. Bias terms are not penalized. Adam uses weight_decay = 0, so L2 enters only through the explicit penalty above.

The response is standardized from the fitting subset during optimization and predictions are transformed back to the original phenotype scale before performance metrics are calculated.

Representative 64-32 network

The largest architecture in the prespecified catalog can be written directly as:

model <- nn_module(
  initialize = function(input_dim) {
    self$hidden1 <- nn_linear(input_dim, 64)
    self$hidden2 <- nn_linear(64, 32)
    self$output <- nn_linear(32, 1)
  },
  forward = function(x) {
    x <- nnf_relu(self$hidden1(x))
    x <- nnf_relu(self$hidden2(x))
    self$output(x)
  }
)

Smaller catalog architectures follow the same pattern with fewer hidden units or one hidden layer. The generic implementation shown next constructs all nine architectures from the same definition.

TorchGenomicMLP <- torch::nn_module(
  "TorchGenomicMLP_CanonicalTuning",

  initialize = function(
    input_dim,
    hidden_units
  ) {
    self$linears <-
      torch::nn_module_list()

    previous <-
      as.integer(input_dim)

    for (h in hidden_units) {
      self$linears$append(
        torch::nn_linear(
          previous,
          as.integer(h)
        )
      )
      previous <- as.integer(h)
    }

    self$output <-
      torch::nn_linear(
        previous,
        1L
      )
  },

  forward = function(x) {
    if (length(self$linears) > 0L) {
      for (
        i in seq_len(
          length(self$linears)
        )
      ) {
        x <- torch::nnf_relu(
          self$linears[[i]](x)
        )
      }
    }

    self$output(x)
  }
)

weight_penalty <- function(
  model,
  l1,
  l2
) {
  weights <- lapply(
    seq_len(
      length(model$linears)
    ),
    function(i) {
      model$linears[[i]]$weight
    }
  )

  weights[[length(weights) + 1L]] <-
    model$output$weight

  zero <- weights[[1]]$sum() * 0
  penalty_l1 <- zero
  penalty_l2 <- zero

  for (w in weights) {
    penalty_l1 <-
      penalty_l1 +
      w$abs()$sum()

    penalty_l2 <-
      penalty_l2 +
      w$pow(2)$sum()
  }

  l1 * penalty_l1 +
    (l2 / 2) * penalty_l2
}

clone_state <- function(model) {
  state <- model$state_dict()

  copy <- lapply(
    state,
    function(x) {
      x$detach()$clone()
    }
  )

  names(copy) <- names(state)

  copy
}

Inner-CV training

The inner analysis set is divided deterministically into:

  • a fitting subset;
  • an early-validation subset.

The frozen inner assessment set remains untouched until prediction of that candidate. Preprocessing is estimated from the fitting subset only.

Early stopping is an optimization mechanism. Its epoch diagnostics are saved but excluded from the tuning rule.

The core optimization step itself is simple: predict the fitting subset, calculate MSE plus the selected penalty, backpropagate, and update the weights.

train_inner_candidate <- function(
  bundle,
  architecture,
  learning_rate,
  l1,
  l2,
  seed
) {
  set_ann_seed(seed)

  x_fit <- torch::torch_tensor(
    bundle$x_fit,
    dtype = torch::torch_float()
  )$to(device = ANN_DEVICE)

  y_fit <- torch::torch_tensor(
    matrix(
      bundle$y_fit,
      ncol = 1
    ),
    dtype = torch::torch_float()
  )$to(device = ANN_DEVICE)

  x_validation <- torch::torch_tensor(
    bundle$x_validation,
    dtype = torch::torch_float()
  )$to(device = ANN_DEVICE)

  y_validation <- torch::torch_tensor(
    matrix(
      bundle$y_validation,
      ncol = 1
    ),
    dtype = torch::torch_float()
  )$to(device = ANN_DEVICE)

  x_assessment <- torch::torch_tensor(
    bundle$x_assessment,
    dtype = torch::torch_float()
  )$to(device = ANN_DEVICE)

  model <- TorchGenomicMLP(
    ncol(bundle$x_fit),
    ARCHITECTURES[[architecture]]
  )$to(device = ANN_DEVICE)

  optimizer <- torch::optim_adam(
    params = model$parameters,
    lr = learning_rate,
    weight_decay = 0
  )

  best_validation_loss <- Inf
  checkpoint_epoch <- NA_integer_
  checkpoint_state <- NULL
  stale <- 0L
  last_epoch <- 0L
  stopped_by_patience <- FALSE

  sync_device()
  fit_start <-
    proc.time()[["elapsed"]]

  for (
    epoch in seq_len(MAX_EPOCHS)
  ) {
    last_epoch <- epoch

    model$train()
    optimizer$zero_grad()

    prediction <-
      model(x_fit)

    loss <-
      torch::nnf_mse_loss(
        prediction,
        y_fit
      ) +
      weight_penalty(
        model,
        l1,
        l2
      )

    loss$backward()
    optimizer$step()

    model$eval()

    validation_loss <-
      torch::with_no_grad({
        torch::nnf_mse_loss(
          model(x_validation),
          y_validation
        )
      })

    validation_value <-
      as.numeric(
        validation_loss$to(
          device =
            torch::torch_device("cpu")
        )
      )

    if (
      is.finite(validation_value) &&
      validation_value <
        best_validation_loss -
        MIN_DELTA
    ) {
      best_validation_loss <-
        validation_value

      checkpoint_epoch <-
        epoch

      checkpoint_state <-
        clone_state(model)

      stale <- 0L
    } else {
      stale <- stale + 1L
    }

    if (stale >= PATIENCE) {
      stopped_by_patience <- TRUE
      break
    }
  }

  sync_device()
  fit_seconds <-
    proc.time()[["elapsed"]] -
    fit_start

  if (
    is.null(checkpoint_state) ||
    is.na(checkpoint_epoch)
  ) {
    stop(
      "No finite early-validation checkpoint."
    )
  }

  model$load_state_dict(
    checkpoint_state
  )
  model$eval()

  sync_device()
  prediction_start <-
    proc.time()[["elapsed"]]

  prediction_scaled <-
    torch::with_no_grad({
      as.numeric(
        model(x_assessment)$to(
          device =
            torch::torch_device("cpu")
        )
      )
    })

  sync_device()
  prediction_seconds <-
    proc.time()[["elapsed"]] -
    prediction_start

  list(
    prediction = unscale_y(
      prediction_scaled,
      bundle$y_scaler
    ),
    early_stop_epoch =
      as.integer(checkpoint_epoch),
    last_epoch =
      as.integer(last_epoch),
    stopped_by_patience =
      stopped_by_patience,
    hit_epoch_ceiling =
      last_epoch >= MAX_EPOCHS &&
      !stopped_by_patience,
    fit_seconds = fit_seconds,
    prediction_seconds =
      prediction_seconds,
    zero_variance_markers =
      bundle$zero_variance_markers
  )
}

Candidate evaluation and selection

Candidate ranking is deterministic and does not include epoch information.

The ranking hierarchy is:

  1. lower mean inner-assessment RMSE;
  2. higher mean inner-assessment correlation;
  3. fewer network parameters;
  4. smaller total penalty coefficient;
  5. smaller learning rate;
  6. candidate ID.

A completed candidate table is therefore sorted by the same hierarchy:

candidate_summary <- candidate_summary[
  order(
    candidate_summary$Mean_RMSE,
    -candidate_summary$Mean_Correlation,
    candidate_summary$Parameters,
    candidate_summary$Penalty,
    candidate_summary$Learning_rate,
    candidate_summary$CandidateID
  ),
]

The first row is the selected candidate. The complete function shown next implements this same ranking across the four inner folds and records incomplete fits separately from successful candidates.

evaluate_candidate <- function(
  bundles,
  model_name,
  architecture,
  learning_rate,
  l1,
  l2,
  seed_base,
  candidate_id
) {
  rows <- vector(
    "list",
    4L
  )

  for (k in 1:4) {
    fitted <- tryCatch(
      train_inner_candidate(
        bundles[[k]],
        architecture,
        learning_rate,
        l1,
        l2,
        seed_base + k
      ),
      error = function(e) e
    )

    if (
      inherits(
        fitted,
        "error"
      )
    ) {
      rows[[k]] <- data.frame(
        Model = model_name,
        CandidateID = candidate_id,
        Architecture = architecture,
        Learning_rate = learning_rate,
        L1 = l1,
        L2 = l2,
        InnerFold = k,
        RMSE = NA_real_,
        Correlation = NA_real_,
        MAE = NA_real_,
        EarlyStop_epoch = NA_integer_,
        Last_epoch = NA_integer_,
        Stopped_by_patience = NA,
        Hit_epoch_ceiling = NA,
        Fit_seconds = NA_real_,
        Prediction_seconds = NA_real_,
        Status = "error",
        Error = conditionMessage(fitted),
        stringsAsFactors = FALSE
      )
    } else {
      rows[[k]] <- data.frame(
        Model = model_name,
        CandidateID = candidate_id,
        Architecture = architecture,
        Learning_rate = learning_rate,
        L1 = l1,
        L2 = l2,
        InnerFold = k,
        RMSE = safe_rmse(
          fitted$prediction,
          bundles[[k]]$y_assessment
        ),
        Correlation = safe_cor(
          fitted$prediction,
          bundles[[k]]$y_assessment
        ),
        MAE = safe_mae(
          fitted$prediction,
          bundles[[k]]$y_assessment
        ),
        EarlyStop_epoch =
          fitted$early_stop_epoch,
        Last_epoch =
          fitted$last_epoch,
        Stopped_by_patience =
          fitted$stopped_by_patience,
        Hit_epoch_ceiling =
          fitted$hit_epoch_ceiling,
        Fit_seconds =
          fitted$fit_seconds,
        Prediction_seconds =
          fitted$prediction_seconds,
        Status = "ok",
        Error = NA_character_,
        stringsAsFactors = FALSE
      )
    }
  }

  folds <- do.call(
    rbind,
    rows
  )

  ok <- folds$Status == "ok"

  summary <- data.frame(
    Model = model_name,
    CandidateID = candidate_id,
    Architecture = architecture,
    Learning_rate = learning_rate,
    L1 = l1,
    L2 = l2,
    Inner_folds_ok = sum(ok),
    Mean_RMSE = if (all(ok)) {
      mean(folds$RMSE)
    } else {
      NA_real_
    },
    Mean_Correlation = if (all(ok)) {
      mean(folds$Correlation)
    } else {
      NA_real_
    },
    Mean_MAE = if (all(ok)) {
      mean(folds$MAE)
    } else {
      NA_real_
    },
    Median_EarlyStop_epoch = if (all(ok)) {
      median(folds$EarlyStop_epoch)
    } else {
      NA_real_
    },
    Max_Last_epoch = if (all(ok)) {
      max(folds$Last_epoch)
    } else {
      NA_real_
    },
    N_epoch_ceiling = if (all(ok)) {
      sum(folds$Hit_epoch_ceiling)
    } else {
      NA_integer_
    },
    Status = if (all(ok)) {
      "ok"
    } else {
      "incomplete"
    },
    stringsAsFactors = FALSE
  )

  list(
    summary = summary,
    folds = folds
  )
}

choose_candidate <- function(x) {
  eligible <- x[
    x$Status == "ok" &
      is.finite(x$Mean_RMSE),
    ,
    drop = FALSE
  ]

  if (!nrow(eligible)) {
    stop(
      "No complete ANN candidate is available."
    )
  }

  eligible$Parameters <- vapply(
    eligible$Architecture,
    function(architecture) {
      parameter_count(
        ncol(geno),
        ARCHITECTURES[[architecture]]
      )
    },
    numeric(1)
  )

  eligible$Penalty <-
    eligible$L1 +
    eligible$L2

  eligible <- eligible[
    order(
      eligible$Mean_RMSE,
      -eligible$Mean_Correlation,
      eligible$Parameters,
      eligible$Penalty,
      eligible$Learning_rate,
      eligible$CandidateID
    ),
    ,
    drop = FALSE
  ]

  # Epoch diagnostics are intentionally absent from the ranking above.
  eligible[
    1,
    ,
    drop = FALSE
  ]
}

From tuning to final fitting

Nested tuning returns one architecture, learning rate, and applicable penalty coefficient(s) for each Scenario × outer split × ANN variant.

The final stage follows one fixed sequence:

  1. take the selected hyperparameters from nested tuning;
  2. use only the 800 outer-analysis individuals to select Best_epoch;
  3. allow at most 3000 epochs during this epoch-selection fit;
  4. reinitialize the network;
  5. refit all 800 outer-analysis individuals for exactly Best_epoch;
  6. predict the untouched 200 outer-assessment individuals.

The 3000-epoch value is a safety ceiling, not the final training length. Outer-assessment phenotypes and true genetic values are excluded from both hyperparameter selection and Best_epoch selection.

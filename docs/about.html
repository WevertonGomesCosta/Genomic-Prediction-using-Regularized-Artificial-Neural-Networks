Objective

This project investigates genomic prediction using regularized artificial neural networks, with emphasis on whether L1 and L2 weight penalties improve predictive performance relative to an unregularized ANN and to a conventional genomic mixed model.

The study contains two complementary branches:

  1. controlled simulated genomic scenarios, in which the true genetic value is known and can be used for independent predictive assessment;
  2. a real Coffea arabica dataset, used to evaluate the models under an applied breeding context.

Model comparison

The canonical model set is:

  • GBLUP_ADE;
  • ANN_0;
  • ANN_L1;
  • ANN_L2;
  • ANN_L1_L2, displayed as ANN-L1+L2.

All ANN variants use the same multilayer-perceptron implementation. They differ only in the coefficients applied to the L1 and L2 penalties on network weights. Bias terms are not penalized.

The ANN objective function is

\[ \mathrm{MSE} +\lambda_1\sum_j |w_j| +\frac{\lambda_2}{2}\sum_j w_j^2. \]

The combined L1+L2 model is therefore described explicitly as simultaneous L1 and L2 neural-network weight regularization.

Simulated genomic data

The simulated branch contains six scenarios that form a genetic-complexity gradient. The scenarios differ in genetic architecture and nominal heritability. Because the design is not a complete factorial combination of number of QTL and heritability, global changes across all six scenarios are not interpreted as the isolated causal effect of either factor.

Within equal-heritability pairs, comparisons can be made more directly between different levels of genetic complexity.

Real coffee data

The real-data branch uses coffee genotype and phenotype information. Genotype quality control and phenotype adjustment are treated as separate analytical steps. The provenance of the adjusted phenotypes is audited against the available raw multi-year phenotypic records before genomic prediction.

Validation and tuning

All models are evaluated using common held-out partitions. ANN hyperparameters are selected only within the outer-analysis data. The outer-assessment sample is reserved for predictive evaluation.

The public simulated-data workflow contains a single canonical ANN analysis. Hyperparameter tuning is an internal stage of that workflow rather than a separate public analysis page. Development sensitivity, boundary, and convergence diagnostics were used to establish and validate the final ANN protocol; their methodological conclusions are incorporated into the canonical analysis and those development modules are not part of the public workflow.

Training epochs are treated as a fixed optimization protocol rather than a scientific tuning dimension. The canonical protocol distinguishes between:

  • hyperparameters selected by inner cross-validation;
  • fixed optimization controls such as maximum training epochs and patience;
  • final model refitting on the full outer-analysis sample.

Reproducible research

The project is implemented in R with workflowr. Source analysis pages are stored under analysis/, rendered website files under docs/, and reusable analysis objects under output/.

The workflow is designed so that routine rendering of the website does not automatically rerun computationally expensive model fitting.

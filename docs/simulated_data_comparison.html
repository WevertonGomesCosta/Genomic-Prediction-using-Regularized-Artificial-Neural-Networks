1. Purpose

This module closes the simulated-data workflow by comparing all seven genomic prediction methods on exactly the same outer-assessment individuals defined in M02:

  • GBLUP_A, GBLUP_AD, and GBLUP_ADE;
  • ANN_0, ANN_L1, ANN_L2, and ANN_L1_L2.

The comparison uses only predictions already produced in M03 and M04. No model is refitted and no hyperparameter is selected here. The known true simulated genetic value is the primary evaluation target; the observed phenotype is reported as a secondary target because it also contains residual variation.

Three principles define the comparison:

  • every method contributes the same 150 Scenario x outer split tasks;
  • every task contains the same 200 held-out individuals for all methods;
  • all 21 unordered method pairs are contrasted within the same outer splits. These paired summaries describe repeated cross-validation results and are not treated as tests based on 150 statistically independent replicates.

3. Evaluation metrics

M03, M04, and M05 use the same held-out evaluation contract.

  • Pearson correlation measures linear association between prediction and target; larger values are better.
  • Spearman correlation measures monotonic rank association between prediction and target; larger values are better.
  • RMSE and MAE measure prediction error on the original target scale; smaller values are better.
  • Bias is mean(prediction - target) and is retained as a secondary calibration diagnostic; values nearer zero are preferable.
  • Slope is the prediction coefficient in lm(target ~ prediction) and is retained as a secondary calibration diagnostic; values nearer one are preferable.
  • No \(R^2\) metric is used.

For the simulated benchmark, the known true genetic value is the primary evaluation target. Therefore the matched pairwise comparisons use exactly four primary genetic metrics: Pearson, Spearman, RMSE, and MAE. Phenotype metrics and the Bias/Slope diagnostics remain available for descriptive summaries but are not included in the pairwise performance-contrast table.

For a pair of methods, positive performance advantage favors Model_1. Higher-is-better metrics use Model_1 - Model_2; lower-is-better metrics use Model_2 - Model_1.

8. Scientific conclusion

Within the prespecified simulated-data benchmark, model performance is evaluated with four primary held-out metrics against the known true genetic value: Pearson correlation, Spearman correlation, RMSE, and MAE. Bias and calibration slope are retained as secondary diagnostics, and no \(R^2\) metric is used.

The seven methods are compared on the same frozen outer splits. All 21 unordered method pairs are evaluated within matched outer tasks, so no GBLUP or ANN method is privileged as the universal reference. The overall and scenario summaries describe the observed performance within the evaluated simulation conditions and prespecified model-search spaces; they do not establish a universal ranking between genomic mixed models and neural networks.

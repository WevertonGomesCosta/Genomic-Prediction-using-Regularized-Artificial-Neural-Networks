1. Objective

This module provides the terminal comparison between GBLUP-ADE and the four ANN variants under the frozen outer-CV design. All competing methods are evaluated on identical outer-assessment individuals.

Prediction of the known true simulated genetic value is the primary outcome. Prediction of the observed phenotype is retained as a secondary outcome. Results are summarized overall, by simulation scenario, and through task-matched ANN versus GBLUP-ADE contrasts.

The module does not fit models, tune hyperparameters, or alter predictions. It combines the canonical outputs from M03 and M04 and verifies that the comparison is made on the same tasks, individuals, and evaluation targets.

4. Evaluation metrics

The same metric definitions are applied separately to prediction of the true simulated genetic value and to prediction of the observed phenotype.

4.1 Prediction metrics

  • Correlation describes linear agreement between prediction and target.
  • RMSE and MAE summarize prediction error on the original target scale.
  • R-squared is calculated as \(1-SSE/SST\), using prediction errors relative to the target mean. It is not defined here as squared correlation and can be negative for genuinely held-out predictions.

4.2 Calibration metrics

  • Bias is the mean prediction error, \(\operatorname{mean}(\text{prediction}-\text{target})\). Zero is the calibration target.
  • Slope is the prediction coefficient in lm(target ~ prediction). A value near one indicates appropriate proportional scaling, although the regression intercept also contributes to calibration.

Correlation, error metrics, and calibration diagnostics answer complementary questions. No single metric is interpreted as establishing universal model superiority.

7. Task-matched ANN vs GBLUP-ADE comparison

7.1 Overall task-matched contrasts

For the three primary genetic-value metrics, the paired advantage is defined so that a positive value always favors the ANN variant:

  • Correlation advantage = ANN correlation - GBLUP-ADE correlation.
  • RMSE advantage = GBLUP-ADE RMSE - ANN RMSE.
  • \(R^2\) advantage = ANN \(R^2\) - GBLUP-ADE \(R^2\).

The same convention is extended to MAE, bias, slope, and the secondary phenotype metrics by comparing the appropriate direction or distance from the calibration target.

performance_advantage <- function(
  metric,
  ann_value,
  gblup_value
) {
  rule <- unname(
    metric_rule[metric]
  )

  candidate_advantages <- list(
    higher =
      ann_value - gblup_value,
    lower =
      gblup_value - ann_value,
    zero =
      abs(gblup_value) - abs(ann_value),
    one =
      abs(gblup_value - 1) -
      abs(ann_value - 1)
  )

  candidate_advantages[[rule]]
}

10. Overall scientific conclusion

Within the prespecified canonical model and ANN architecture search space, GBLUP-ADE provides the strongest overall predictive performance and leads the primary genetic-value metrics across all six simulation scenarios. Among the neural networks, ANN-L1+L2 has the best overall averages by a very small margin over ANN-L1, while ANN-L2 remains close to the unregularized ANN.

These results support a specific conclusion for the frozen design evaluated here; they do not establish a universal ranking between genomic mixed models and all possible neural-network architectures.

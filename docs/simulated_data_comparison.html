Purpose

This module is the terminal comparison stage of the canonical simulated-data workflow. It compares the saved GBLUP-ADE results with the four saved ANN variants after both modeling branches have been completed.

The page does not fit or tune any model. It consumes the canonical outputs from simulated_data_gblup.Rmd and simulated_data_ann.Rmd, verifies direct comparability under the frozen validation design, computes the descriptive comparison tables, and checks them against the versioned canonical comparison outputs.

The primary outcome is prediction of the true simulated genetic value. Phenotype prediction is retained as a secondary outcome. Conclusions concerning ANN performance are restricted to the prespecified canonical ANN architecture and hyperparameter search space.

Comparison contract

A direct comparison is allowed only when all of the following invariants hold:

  1. GBLUP-ADE contains exactly 150 outer-CV tasks.
  2. Each ANN variant contains the same 150 TaskID/SplitID combinations.
  3. Scenario, repetition, fold, and split identifiers agree across methods.
  4. Each task contains the same 200 outer-assessment individuals for GBLUP-ADE and every ANN variant.
  5. Observed_Phenotype and True_Genetic_Value are identical for those paired individuals across methods.
  6. All model fits and held-out predictions used in the comparison have status ok, and all reported comparison metrics and predictions are finite.
  7. No ANN tuning, ANN final fitting, or GBLUP-ADE fitting is executed by this page.
  8. Paired summaries are descriptive; repeated CV folds are not treated as statistically independent observations for naive significance testing.

find_project_root <- function(start = getwd()) {
  path <- normalizePath(start, winslash = "/", mustWork = TRUE)

  repeat {
    if (file.exists(file.path(path, "_workflowr.yml"))) {
      return(path)
    }

    parent <- dirname(path)

    if (identical(parent, path)) {
      stop("Could not locate workflowr project root.")
    }

    path <- parent
  }
}

result_key <- function(x) {
  paste(
    x$Scenario, x$Repetition, x$Fold, x$SplitID, x$TaskID,
    sep = "|"
  )
}

assessment_key <- function(x) {
  paste(
    x$Scenario, x$Repetition, x$Fold, x$SplitID, x$TaskID,
    as.character(x$ID),
    sep = "|"
  )
}

g_result_keys <- sort(result_key(gr))

ann_result_keys_match <- vapply(
  expected_ann_models,

Paired ANN versus GBLUP-ADE comparison

A positive performance_advantage always means that the ANN variant performed better than GBLUP-ADE for the metric under consideration. Correlations and \(R^2\) are maximized, RMSE and MAE are minimized, bias is evaluated by distance from zero, and slope is evaluated by distance from one.

performance_advantage <- function(metric, ann_value, gblup_value) {
  if (metric %in% higher_better) {
    return(ann_value - gblup_value)
  }
  if (metric %in% lower_better) {
    return(gblup_value - ann_value)
  }
  if (metric %in% zero_target) {
    return(abs(gblup_value) - abs(ann_value))
  }
  if (metric %in% one_target) {
    return(abs(gblup_value - 1) - abs(ann_value - 1))
  }

  stop("Unclassified metric: ", metric)
}

g <- gr[, c("TaskID", "SplitID", metrics)]
names(g)[-(1:2)] <- paste0(names(g)[-(1:2)], "_GBLUP")

paired_list <- list()

for (model in sort(unique(ar$Model))) {
  a <- ar[
    ar$Model == model,
    c("TaskID", "SplitID", "Scenario", metrics)
  ]

  z <- merge(a, g, by = c("TaskID", "SplitID"), all = FALSE)

  if (nrow(z) != 150L) {
    stop(model, ": expected 150 paired tasks, got ", nrow(z))
  }

  for (metric in metrics) {
    ann_value <- z[[metric]]
    gblup_value <- z[[paste0(metric, "_GBLUP")]]
    raw_difference <- ann_value - gblup_value
    advantage <- performance_advantage(metric, ann_value, gblup_value)

    paired_list[[length(paired_list) + 1L]] <- data.frame(
      Model = model,
      Metric = metric,
      N = length(raw_difference),
      Mean_ANN = mean(ann_value),
      Mean_GBLUP = mean(gblup_value),
      Mean_raw_difference = mean(raw_difference),
      Median_raw_difference = median(raw_difference),
      Mean_performance_advantage = mean(advantage),
      Median_performance_advantage = median(advantage),
      ANN_better = sum(advantage > 0),
      Equal = sum(advantage == 0),
      GBLUP_better = sum(advantage < 0),
      stringsAsFactors = FALSE
    )
  }
}

  ]

  z <- merge(a, g, by = c("TaskID", "SplitID"), all = FALSE)

  for (scenario in sort(unique(z$Scenario))) {
    zs <- z[z$Scenario == scenario, , drop = FALSE]

    if (nrow(zs) != 25L) {
      stop(
        model, " / ", scenario,
        ": expected 25 paired tasks, got ", nrow(zs)
      )
    }

    for (metric in metrics) {
      ann_value <- zs[[metric]]
      gblup_value <- zs[[paste0(metric, "_GBLUP")]]
      advantage <- performance_advantage(metric, ann_value, gblup_value)

      paired_scenario_list[[length(paired_scenario_list) + 1L]] <- data.frame(
        Scenario = scenario,
        Model = model,
        Metric = metric,
        N = nrow(zs),
        Mean_advantage = mean(advantage),
        Median_advantage = median(advantage),
        ANN_better = sum(advantage > 0),
        Equal = sum(advantage == 0),
        GBLUP_better = sum(advantage < 0),
        stringsAsFactors = FALSE
      )
    }
  }
}

paired_scenario <- do.call(rbind, paired_scenario_list)
rownames(paired_scenario) <- NULL

frames_equal <- function(saved, computed, tolerance = 1e-12) {
  if (!identical(names(saved), names(computed)) || nrow(saved) != nrow(computed)) {
    return(FALSE)
  }

  for (name in names(saved)) {
    x <- saved[[name]]
    y <- computed[[name]]

    if (is.numeric(x) && is.numeric(y)) {
      if (!all(is.finite(x)) || !all(is.finite(y))) {
        return(FALSE)
      }
      if (!all(abs(x - y) <= tolerance)) {
        return(FALSE)
      }
    } else if (!identical(as.character(x), as.character(y))) {
      return(FALSE)
    }
  }

  TRUE
}

Main findings

Within the prespecified canonical model and ANN architecture search space, GBLUP_ADE has the highest overall mean genetic correlation.

Among the neural-network variants, ANN_L1_L2 has the highest overall mean genetic correlation. ANN variants should be interpreted together with the regularization pattern rather than from a single metric in isolation.

GBLUP-ADE has the highest mean genetic correlation in 6 of 6 scenarios and the lowest mean genetic RMSE in 6 of 6 scenarios.

These results do not establish a universal ordering between genomic mixed models and all possible neural-network architectures. They describe performance under the frozen outer-CV design and the prespecified canonical ANN search space used in this project.

Reproducibility

A normal render reads the saved GBLUP-ADE and ANN result and prediction objects, audits task-level and individual-level comparability, recomputes the comparison summaries, and verifies the four canonical CSV exports. It does not run ANN tuning, final ANN fitting, or GBLUP-ADE fitting.

The canonical exported comparison tables are stored under output/simulated/comparison/.
